# 真实感蒸馏：基于提交视频的可执行规则

## 观察边界

本页来自用户提交的约 211 秒、1280×720、30fps 视频的抽帧视觉分析。素材呈现写实人物访谈、街区/店内生活空间、安保人员、运动员与办公空间的短片示例，并穿插分镜与生成界面。下列为可观察画面规律和可复用推断，不把视频中的具体人物、品牌、台词或界面当作可复制素材。

## 1. 真实感不是滤镜，是因果一致

生成提示词要同时给出“物理原因 → 可见结果”，而不是只写“真实/电影感/高质量”。每个要素只引入能被同镜中其他要素验证的细节：

- 光：说明主光来源、方向、软硬、遮挡和其在皮肤、衣料、玻璃、湿地或金属上的不同反应；同场不可出现无来源的第二套戏剧性轮廓光。
- 空间：放入与人物职业和行为有因果关系的少量物件（例如门岗、架子、办公桌、路边车辆），说明前中后景、遮挡和可用路径；禁止“泛用装饰堆满房间”。
- 服道化：从角色的职业、时代、天气、工作状态推导制服结构、磨损、鞋底、携带物、发型与妆面；材质和数量与动作接触点一致。
- 身体：动作先有准备、接触和余波。脚踩地、手握物、重心移动、衣摆/头发/球体/尘土的延迟反应必须互相对应。
- 摄影：指定焦段感、机位、景深层级和对焦对象。近景用背景柔化和自然微表情，广景用可读空间与人物尺度；禁止无动机的变焦、焦点搜索和无人机式漂浮。
- 时间：让眨眼、呼吸、吞咽、目光停顿、布料回弹、背景行人或风在不同速度层次中持续发生。一个镜头只承载一个主要动作和一个情绪变化。
- 声音：为同期声、环境底噪、关键接触音和静默分别指定来源。声音可帮助观众相信画外空间，但不可用强音乐掩盖画面物理错误。

## 2. 从参考视频提炼的镜头组织

以“人物反应/采访 → 行为或物件局部 → 环境建立 → 反应或结果”组织短段落。该视频反复用人物近景、行动局部（如鞋、球、手势）、可辨识环境和反应镜头切换，让观众先读到身份和动机，再读到动作的重量。

对每个 `SHOT-ID` 写一条真实感因果链：

```text
职业/处境 → 服装与可接触物 → 空间限制 → 可见动作阶段 → 光与材质反应 → 声音线索 → 终帧余波
```

若不能写完整因果链，缩小动作，回到角色/场景/道具锚点；不要额外加形容词。

## 3. 写入视频提示词的真实感块

将以下块作为第十二节写在终帧之前，并将其拆入各个分时段节拍：

```text
【真实感物理合同】
主光与可见光源：……
材质与接触：皮肤/布料/硬质物/地面分别如何受光、受力、留下什么细微变化：……
动作链：准备 → 接触/受力 → 惯性/余波；重心、手指、脚底和道具的位置：……
时间层：人物微动作……；环境慢变量……；禁止的突变……
摄影限制：焦段感……，焦点平面……，允许的机位移动及物理/叙事触发……
声音证据：同期声……，环境声……，拟音……，静默……；未核验原生音频时标“后期”。
```

## 4. 真实感 QA 与修复

逐镜检查：光源是否可解释；接触是否成立；体重是否落在支撑面；布料/头发/尘雾是否有符合速度的迟滞；景深和焦点是否稳定；环境物件是否服务角色；声源是否有画内或画外依据；剪切是否落在动作、视线或声音变化上。

新增失败编码：

| 编码 | 症状 | 首要修复 |
|---|---|---|
| F16 | 画面精致但没有生活因果 | 补职业—物件—空间—动作链，删无关装饰 |
| F17 | 光线漂亮但来源矛盾 | 重写唯一主光与实景光，统一材质反应 |
| F18 | 动作缺重量或余波 | 降低动作负荷，锁定支撑点/接触点/惯性 |
| F19 | 镜头或焦点像算法漂移 | 固定机位/焦点或补全移动路径、触发、停止条件 |
| F20 | 声画无共同空间 | 为声源指定位置、距离、反射与进入/退出时机 |

一次只针对一个 F 编码改变一个主要变量。连续三次失败，退回上一批准锚点或拆镜。
