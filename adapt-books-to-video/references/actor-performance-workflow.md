# 演员表演：剧本到资产、提示词与实片

适用于人物驱动的故事片、对话和用户反馈“僵硬、没有演技”的修复。先读本页，再按需要查 `performance-and-microexpressions.md` 的可见部位及 `character-realism-distillation.md` 的身份/光影规则。纯物件、无人场景无需套用人物合同。纪录片不为真实人物捏造内心；重建表演标明创作解释。

## 1. 剧本先有对人的行动

每个主要表演节拍建立唯一 `PERF-ID`，关联 SCRIPT-BEAT-ID、角色和场次。记录角色想让谁做什么、使用什么策略、对方/环境给了什么信息、角色怎样接收以及是否改变策略。可用行动动词如催促、安抚、试探、敷衍、遮掩、争取、确认，避免只写“悲伤、自然、有演技”。这些是表演解释，不授权增删用户锁定的对白或情节。

剧本正文只保留关键的可拍行为和必要停顿；细部放表演台账，不把肌肉说明塞满剧本。潜台词在内部记录为创作解释，不生成额外旁白。平静、持重、压抑不是无反应；通过注视对象、接收信息后的选择或身体接触表现。若角色本就保持原行动，记录“维持及原因”，不强造情绪转折。

## 2. 导演台排一次可演的接收与回应

每个承担戏剧信息的可见角色写：

```text
PERF-ID / SCRIPT-BEAT-ID / GEN-ID / SHOT-ID / 角色
对象与行动目标 / 策略 / 潜台词边界
入态：已经在做什么、看谁、身体支撑在哪里
刺激：具体台词片段、声源、动作或信息；可见/可听发生点
接收：最先改变的1个可见信号，或有动机地维持
回应：选择1—2个可读身体/面部通道；如何继续行动或抑制反应
出态：注意力、身体与关系的新状态或有意维持状态
对白：句内意群、重音、换气、对谁说；听者同期在做什么
可读窗口：角色何时多大、是否遮挡/失焦/运动模糊；表演出现及停留区间
资产映射：表情卡格号 → 首帧状态 → 故事板格号 → 提示词语句
```

时序以事件驱动为主，秒数是预演目标。不要把每个字、眨眼和眉毛位置写成执行保证。角色先听见/看见再回应，不能无理由提前反应。说话者不靠一直张嘴表演；听者不能等轮到台词才“上线”。口型、气息、手势错开，不安排人人同频运动。

按景别选择表达通道：近景用眼睑/嘴角/下颌等1—2处及声音；中景用头肩、目光对象、手与道具；全景用步速、走停、距离、朝向和群体关系。最终480P看不清的微表情标 `NOT_OBSERVABLE`，不能要求全景毛孔级演技。若关键含义只能靠脸读懂，应在不损害已锁构图的前提下调整取景、停留或另设反应镜；不擅自拆掉用户要求的同框拉远。

群演按功能分组，写谁先注意到什么、谁仍忙于原事、谁随后跟随。只给承担信息的前排人物独立动作，其余保留自然持续任务；不固定人人转头的毫秒数，也不以随机小动作充当演技。

## 3. 从表演台账到静态资产

不增加默认正式卡数量。主角色仍为一张资料卡、一张六种剧情表情卡；表情卡不是六格时间连续故事板。

- 资料卡只锁身份；表情卡六格选该角色真实剧情中的状态，建立格号→PERF-ID→触发→可见特征映射。无必要不套“喜怒哀乐惊恐”通用套装，也不要求六格都夸张。
- 表情卡用短标签，详细表演写在台账。比较中性基线与剧情状态，检查是否有可辨差异且仍是同一人；六张相同脸不能仅因身份一致通过。差异可以在视线、口部张力或头颈姿态，不要求每格大哭大笑。
- 首帧锁该条的真实入态。若1秒后才被刺激，不在首帧预先做出峰值表情。灯光与面部材质服从场景。
- 每条一张六格故事板，格内承接本条时间弧；含关键表演时，利用现有格子呈现刺激前、接收/回应、出态，不额外增格或伪造六次切镜。记录格号、PERF-ID及该格相对前格改变了什么。全景用空间/身体变化验收，不硬塞大脸近景破坏镜头。
- 静态卡通过只说明状态可读、身份与空间成立，不能证明反应延迟、语气、动作过渡或演技已经通过。

## 4. 编译到模型提示词

审计版保留完整台账；提交版每个主要可见角色保留“原本在做什么→接收到什么→做出什么可见回应→停在哪里”，加必要的声音指示。明确表情参考控制的格号、状态和适用时段，不冻结整个镜头的眉眼与嘴唇，也不把表情卡峰值强加给全部时间。

用 `performance_constraint_map` 登记 PERF-ID、故事板格、实际参考图/格号、提交语句及验收点。尚无真实参考写null，不能编造槽位。检查编译后是否只剩“自然、克制、平静”的形容词，或只保留身份而遗漏接收/回应。

模型只接收可观察动作，不需要“内心复杂”“奥斯卡演技”、全套七区控制、精确肌肉毫米数或固定眨眼周期。减少冲突优先于增加提示词：同一时刻不让角色吞咽、说话、抿嘴并喘气。卡片锁身份不等于把眼睛和肩膀锁死。

## 5. 验收与修复闭环

文本检查 `DESIGN_CHECKED`；图片检查 `STATIC_STATE_CHECKED`；视频表演检查单独记录 `PERFORMANCE_QA: PENDING / PASS / FAIL`。不得用清单验证器、嘴动或有一次眨眼替代表演验收。

播放实际片段，在PERF-ID下记时间戳和可见证据：

|检查|通过依据|失败定位|
|---|---|---|
|目标与对象|目光、姿态或声音面向正确对象，行为有目的|看空处、面向镜头表演、无对象机械动作|
|接收与回应|刺激发生后有可读回应或有意保持的依据|提前反应、刺激后完全断线、反应无原因|
|身体与声音|呼吸、语气、手/重心属于同一行动|嘴动身体冻住、呼吸与句子冲突、手势无重心|
|差异与连续|角色有各自节奏，入态和出态连贯|所有人同脸同拍、峰值全程不退、重置表情|
|可读性|在最终尺寸、景别和停留长度下读得到关键动作|脸太小、被遮住、变化只存在于提示词|

用户说旧片僵硬时先确认实际观看范围；未看旧片只报告“流程风险”，不能断言模型或某资产就是根因。修复按层定位：没有目标/刺激→改导演台；静态表情不区分→修表情卡；首帧已到峰值→修锚点；文字弧未传到模型→修编译；全景不可读→修调度/取景；有状态无过渡→测试动作负荷和反应窗口。每次只改主要变量，固定其他输入并对比实际时码。三次同因失败后改可解释的表演包装，不无限重抽。

## 6. 应用示例：焦急迎客（非固定项目规则）

“主人悲伤焦急”可细化为：主人扶门框等候，注意到来者后重心向前、先吸气再叫“上师来了！”，接着把“快，快迎”说给门边的人，仍关注入口。全景主要读前倾、朝向和急缓差，近景才采用下睑张力及句尾未放松的嘴角。听者先确认来者再调整位置；安静独行者继续原步速，视线留在通路。效果来自不同的目的和接收过程，不来自人人加一个皱眉。
