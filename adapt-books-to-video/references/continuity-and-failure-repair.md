## 1. 连续性合同

连续性不是形容词，而是需要逐字复用和逐项检查的状态。

为每名主要人物冻结一条中文身份串，包含年龄、稳定脸部结构、一个可检查标记、发型和一个服装锚点。相关提示词逐字复用，不在近景中重新润色，不在不同模型版本间临时翻译。

为每个场景冻结 `SCENE-xx-SPATIAL-LOCK`：坐标/参考边、边界与开口、门窗/道路、主地标、材料、时间、天气、光向、V01–V09 允许摄影机区和地标可见性矩阵。为关键道具冻结外形、尺寸、材料、损耗、持握手、方向和当前状态。

## 2. 状态账本

每个镜头记录开始状态和结束状态：

```text
人物脸/年龄/发型
服装逐层及开合、湿度、污损
左右手、道具位置/方向/数量/剩余量
伤痕、妆面、汗、泥、水等不可逆状态
主光方向、高度、硬软与实景灯开关
时间、天气、风向、地面积水/尘土
门窗家具及固定地标
画面运动方向、动作轴线、视线高度
摄影机高度、焦段观感、焦点平面
摄影语言、运动触发/路径/停止、镜头能量
上一/下一镜共享向量、主转场方式、J/L 声音桥与后期责任
主色、饱和度、黑位和颗粒
呼吸、重心、表情稳定终态
PERFORMANCE_BASELINE、触发物、最小反应、抑制/发展与稳定终态
FACE_INTEGRATION_LOCK：当前场景主光/环境补光、面部遮挡阴影、皮肤/头发/织物反射、边缘色温与景深
```

连续生成才要求前片实际批准终态；普通剪辑按世界/眼线关系衔接，允许正确反打，计划与实际终态分别登记。发生跳时、换装、天气变化或空间移动时，单独声明状态迁移，不让模型自行猜测。

## 3. 失败编码

| 编码 | 症状 | 首查原因 |
|---|---|---|
| F01 | 人脸、年龄或体型漂移 | 身份串被改写、头转过大、镜头过长、参考任务冲突 |
| F02 | 发型或服装层次改变 | 未冻结逐层状态、参考图服装冲突、遮挡后重建 |
| F03 | 手部/道具穿插或数量错误 | 静态锚点已错、动作过多、左右手和接触点不清 |
| F04 | 场景地标移动、复制、镜像 | 没有空间地图、机位描述相对关系错误、参考图互相冲突 |
| F05 | 光向、时间或天气跳变 | 反打默认补光、未重复光源状态、续写未使用终帧 |
| F06 | 动作轴线、视线或屏幕方向错误 | 跨轴无过渡、人物坐标未锁、反打视线高度缺失 |
| F07 | 动作无物理重量、脚滑、衣物橡胶化 | 动作阶段过密、缺少接触/重心/惯性、单镜负荷过高 |
| F08 | 表情僵硬、同步或突然跳变 | 只有情绪名、无触发和时间弧、强度过高 |
| F09 | 摄影机漂移、焦点搜索、意外变焦 | 运镜无起止和动机、同时要求多种运动、焦点平面未命名 |
| F10 | 历史、宗教或地域错误 | 风格覆盖压过史料、参考污染、推断未标记 |
| F11 | 参考卡文字/边框/无关人物进入画面 | 把审核板、区域引导或密集宫格当成生成参考 |
| F12 | 时间段遗漏、重叠或动作提前完成 | 时间轴未校验、一个节拍含多个主动作 |
| F13 | 字幕、水印、品牌或乱码 | 提示词或参考图含文字、模型自行补标识 |
| F14 | 提交提示词遗漏硬约束 | constraint_map 缺项、引用职责不清或动作/摄影/声音/连续性缺失；不因篇幅较短或合并小节判失败 |
| F15 | 参考资产不可追溯或职责冲突 | ID/文件名/状态不一致、漏写来源链或上传顺序、同图承担冲突职责 |
| F16 | 画面精致但没有生活因果 | 未写职业—物件—空间—动作链、装饰与行为无关 |
| F17 | 光线漂亮但来源矛盾 | 主光/实景光未锁定、材料反应不一致 |
| F18 | 动作缺重量、接触或余波 | 支撑点/重心/接触点不清、动作负荷过高 |
| F19 | 镜头或焦点像算法漂移 | 机位路径、触发/停止或焦点平面缺失 |
| F20 | 声画没有共同空间 | 声音未给画内/画外来源、距离或进入/退出时机 |
| F21 | 小说内容被逐段平移 | 没有目标、阻力、选择、代价或状态变化 |
| F22 | 黄金三秒空、晚或骗点 | 首帧没有失衡/赌注、承诺未在期限内兑现 |
| F23 | 场景没有转折 | 策略、信息、权力或关系没有改变 |
| F24 | 悬念无结果或无后果 | 只停在电话/信件/来人，没有可见新代价 |
| F25 | 对话在解释而非行动 | 缺对抗、潜台词、可视化行为或反应 |
| F26 | 季、集、镜头承诺断裂 | 核心问题、EP-ID、HOOK-ID 与 SCRIPT-BEAT-ID 映射失效 |
| F27 | 16:9 短剧/漫剧不可读或不可生成 | 首眼混乱、文字负荷过大、人物/动作超出单镜能力 |
| F28 | 运镜没有可见叙事动机 | 未写触发/路径/停止或移动后新增信息；用摇晃/推拉替代调度 |
| F29 | 跨片段几何或镜头能量断裂 | 轴线、视线高度、屏幕方向、镜头高度/焦段感或光向无故跳变 |
| F30 | 转场没有共享向量 | 未写动作/构图/视线/光/环境/声音中的至少一项，或两端不匹配 |
| F31 | 单段摄影机与行动负荷过高 | ≤15 秒内多次独立转折、多种无关运镜、复杂多人交接或不可控长路径 |
| F32 | 最终提示词依赖专名风格或复刻风险 | 未把分析参考编译为可观察参数，或出现可识别镜头/角色/台词/美术复刻 |
| F33 | 把未核实转场能力当模型能力 | 未验证的切换、叠化、擦拭、声桥或多镜剪辑没有标为后期制作 |
| F34 | 人物像静态肖像或机械循环 | 缺少有触发的活性证据，或精确周期眨眼/同步小动作取代了注意力反应 |
| F35 | 面部、口型、手、呼吸与重心互相矛盾 | 情绪只写名称，未按触发→最小反应→抑制/发展→稳定编排 |
| F36 | 表情参考卡无法转化为镜内表演 | 未标触发、可见区域与强度，或用密集动作板破坏身份参考密度 |
| F37 | 脸像瓷娃娃、贴图或独立肖像 | 泛化磨皮/统一高光，缺场景光下的面部遮挡和材质分离 |
| F38 | 人物身份正确但不属于当前场景 | 资料卡棚拍光/景深迁移进剧情镜头，人物边缘色温、曝光或景深与场景冲突 |
| F39 | 空间锁无法导出某一机位 | 场景只写氛围，没有边界、开口、站位或可见性关系 |
| F40 | 平面验证与多机位卡拓扑冲突 | 未从同一 `SPATIAL-LOCK` 出图，或修图时只改了一层 |
| F41 | 反打、门洞、视线或通行线错误 | 某个 Vnn 朝向/轴线不符合锁定关系，物件为面对镜头而旋转 |
| F42 | 镜头引用站位与场景卡不一致 | `SHOT` 未注明 Vnn 或锚点没有保留该站位的地标关系 |
| F43 | 资产在版本、文本定位或来源层未锁定时就进入生成 | 缺少选定版本、定位或 `ASSET-EVIDENCE-CARD` |
| F44 | 人物/场景细节被声称为史实，但仅有后世图像学或无依据参考 | 混淆 `HISTORY`、`ICONOGRAPHY` 与 `INFERENCE` |
| F45 | 场景/道具的时代、地域、材料或平面缺证据 | 未选生产解释层，或未做研究/馆藏检索 |
| F46 | 证据卡、来源链、门禁状态或生成后比对缺失/不一致 | 资产台账先于事实建立，或状态未回写 |
| F47 | 模型添加了未授权的文化、宗教、身份或历史细节 | 提示词/锚点没有写不得推导项，或错误地把风格当事实 |
| F48 | 从社会/种姓/族群标签推出表型、服装或住宅 | 未完成身份—物质文化研究，或把 `CASTING_CHOICE` 当史实 |
| F49 | 空间稳定却是空舞台，人物没有可见目标、阻力、行动支点或合理留空 | 缺 `SCENE-xx-PRODUCTION-DESIGN-BREAKDOWN`，或未把它写入空间锁 |
| F50 | 道具/陈设无证据边界、固定位置、使用者或初末状态 | 把“丰富画面”当用途，未建证据卡/形制串 |
| F51 | 六格只是近似站姿，没有准备—压力—变化—余波的状态链 | 缺 `ACTION-PROP-BEAT`，或锚点/调度没有可检查的物件/空间变化 |
| F52 | 开场首眼没有明确观众问题，或多个开场类型竞争 | 缺 `OPENING-PROMISE-CARD`，或没有选择主 `OPENING-MODE` |
| F53 | 壮观画面、人物特写或世界规则没有连接后续目标/证据方向 | 只做了炫示，没有首段可见因果与交棒 |
| F54 | 开场承诺没有兑现期限、实际兑现或下一镜合同 | `HOOK-ID`/`SCRIPT-BEAT-ID`/镜头终态未映射 |
| F55 | 纪录片将虚构冲突、未标注复原或戏剧表演冒充开场事实 | 证据/复原标签缺失，或用强刺激覆盖事实边界 |

## 4. 最低成本修复阶梯

按顺序尝试，找到能处理根因的最低一级：

1. **状态/提示词修正**：补一个缺失不变量，删除冲突形容词或多余动作；
2. **参考素材替换**：用更干净、更大、更单一任务的参考替代密集板；
3. **静态锚点局部修复**：先修手、道具、服装或地标，再做图生视频；
4. **重新生成镜头锚点**：构图或空间根本错误时，不继续动画；
5. **拆分镜头**：动作负荷、头部旋转、多人互动或时长超过稳定范围；
6. **重排镜头/改用剪辑解决**：模型不适合完成该摄影机路径或复杂交互。

不要一次改变人物参考、场景参考、提示词、时长和模型五个变量；否则无法判断哪个修复有效。

## 5. 重试规则

每次失败记录：资产 ID、失败编码、证据截图/观察、推测根因、只改变的变量、结果、是否批准。

同一失败编码连续三次出现时停止盲目重抽，强制：

- 检查源锚点；
- 降低动作或参考密度；
- 缩短/拆分镜头；
- 改变输入形态或重新规划镜头。

只有不合格资产重生成。批准资产保持不变，防止修一个问题时破坏已锁定的身份与空间。

## 6. 验收

- 每个跨镜头人物、场景和道具是否有逐字冻结串？
- 每个镜头是否记录开始/结束状态和批准终帧？
- 视觉、剧本与移动端检查是否覆盖 F01–F55，而不是只写“整体良好”？
- 每个近景是否把身份锁与 `PERFORMANCE_BASELINE` 分开，并以非机械眨眼/视线/呼吸和身体余波证明角色活性？
- 每个近景是否以 `FACE_INTEGRATION_LOCK` 将脸部阴影、材质、边缘色温与景深绑定当前场景，而不是迁移资料卡棚拍光？
- 每条镜头边是否有一项共享向量、恰一种主转场，以及模型/后期责任？
- 每个 recurring scene 是否有 `SPATIAL-LOCK`、V01–V09 可见性矩阵，并且每个镜头只引用实际存在、已批准的 Vnn？
- 每个进入故事板的场景是否有生产设计拆解，且英雄/行动道具或已声明的无道具压力、动线、实景光和终态已进入空间锁？
- 每张接触表是否表达本任务的可检查叙事变化；反应/插入镜是否有功能，而不是为凑三个动作过载？
- 每个开场/回归段是否有 `OPENING-PROMISE-CARD`，且一个主要观众问题、0–3 秒可见因果、兑现映射和下一镜交棒都已被批准？
- 每个资产是否先有 `ASSET-EVIDENCE-CARD`、`PASS` 门禁、生产解释层与生成后逐项比对，而没有用叙事身份、后世图像或模型默认补全为历史事实？
- 重试是否一次只改变一个主要变量并记录结果？
- 连续三次同类失败后是否停止盲抽并升级处理？
- 历史错误是否回到证据档案修正，而不是仅加负向词？

## 7. 失败码作用域与实际视频

历史 F52/F53 在空间、道具和开场文件有重号。保留旧记录，新增报告必须写 `failure_scope` 与 `code`，例如 SPACE:F52、PROP:F53、OPENING:F52、OPENING:F53；不能仅凭裸编号决定修复。F56–F59 参照 screenwriting-directing-overlay.md，F60–F63 参照 cinema-composition-overlay.md。实际视频与桥接按 video-result-qa.md 验收，不从提示词/图片 PASS 推定成片通过。
