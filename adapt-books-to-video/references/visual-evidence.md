# 实物视觉证据与形制锁定

在描述任何法器、兵器、乐器、服装部件、家具、建筑构件、车船、器皿或其他有真实形制的物件之前阅读本文件，并与 `asset-evidence-gate.md` 一起用于角色、场景与镜头资产。

## 1. 为什么必须看图

文字描述不足以锁定形制。「锡杖」「胡床」「幞头」这类名词在不同时代、地区和宗派下形制差异极大，只凭名词生成必然得到通用幻想造型。**必须先找到实物或同期图像，再写提示词。**

判定标准：如果一件物品在成片中会被观众看清，或它是人物身份的识别标志，就必须有视觉证据卡，否则不得进入任何交付图。

## 2. 图像检索流程

对每一件需要锁定的物件执行：

1. **确定检索名**：写出该物件在原文语言中的名称、学术名、异名与英文名。例：锡杖 / 錫杖 / khakkhara / 有环杖。名词错了，检索结果全错。
2. **限定时代与地域**：把检索名与目标时代、地域组合。例：「唐代 锡杖 出土」「正倉院 錫杖」「Tang dynasty khakkhara museum」。不加时代限定的检索会返回现代宗教用品和游戏道具。
3. **优先检索图像而非文章**：目标是博物馆藏品页、发掘报告图版、寺院文物普查、正仓院/故宫/大英/大都会等馆藏数据库、石窟与壁画摹本、同期绘画与雕塑。
4. **排除污染源**：现代法器电商图、影视剧照、游戏与动漫设定、AI 生成图、同人插画一律不作为形制依据，只可用于发现更好的来源，标 `D` 级。
5. **至少两条独立证据**：一件关键物品需要至少两个互相独立的可归属图像来源；只有一条时把置信度记为 `低` 并在不确定性台账登记。
6. **无法找到时**：明确写「未找到可归属实物证据」，选择一个有依据的近似形制并标 `INFERENCE`，禁止编造精确细节。

## 3. 视觉证据卡

每件锁定物件建一张卡，写入 `02-research-dossier.md`：

```text
物件 ID: PROP-01 六环锡杖
检索名: 锡杖 / 錫杖 / khakkhara
证据来源: [S-0xx] 馆藏名 + 藏品编号 + 年代 + 稳定链接 + 访问日期
证据等级: A / B / C
时代与地域: ...
可数特征: 环数、股数、节数、层数、扣数（必须给确定数字）
形态特征: 整体轮廓、比例、长度与人体的关系、各段分界
材质与工艺: 材料、表面处理、锈蚀/磨损、接缝与铸造痕迹
握持与使用: 谁持、单手或双手、握在哪一段、静止与行走时的角度
禁止项: 常见的错误形制（写清楚要避免什么）
标签: HISTORY / ICONOGRAPHY / INFERENCE
置信度: 高 / 中 / 低
```

**可数特征必须给具体数字**，例如「杖头两侧各三环，共六环」而不是「若干金属环」。模型对模糊数量的默认输出通常是错的，这是锡杖类失败的主要原因。

## 4. 形制锁定串

由证据卡压缩出一句可复用的中文形制串，逐字写进所有相关提示词，不得逐镜改写：

```text
PROP-01 形制串：素铁杖身，顶端桃形扁平杖头，杖头两侧各挂三枚可数圆环共六环，
环径约杖头宽度三分之一，杖身长度约与持杖者身高相当，末端为素铁包头，
表面有使用磨痕与暗哑氧化，无宝石、无缠绕纹样、无发光特效。
```

同时写一条否定串，列出该物件最容易被生成错的形态：

```text
PROP-01 否定串：禁止三叉戟形、禁止法轮形、禁止环数不可数或多于六环、
禁止环挂在杖身中段、禁止现代抛光不锈钢、禁止镶嵌彩色宝石、禁止自发光。
```

## 5. 形制物件的交付

关键形制物件默认在 `CHAR-xx-PROFILE-CARD` 的三视图中保持可辨认与可数。

当一件物件同时满足下列两条时，追加交付一张 `PROP-xx-CARD`：

- 它是人物身份或叙事的识别标志；
- 它在成片中至少一次以中近景出现，或它已经出现过形制失败。

`PROP-xx-CARD` 规格：16:9 整版，一次生成，`1×3` 或 `2×2` 分区，分别为整体全长视图、握持段细节、关键端部细节（如杖头与环）。统一中性背景与统一光位，除物件名一处短中文标题外无其他文字。它是交付件也是模型参考件，计入交付数量。

## 6. 生成后比对

每张含关键物件的交付图出图后，把它与证据图像并排比对，逐项检查：

- 可数特征数量是否与形制串一致（数出来，不要目测「差不多」）；
- 整体轮廓与比例是否落在证据范围内；
- 材质与工艺痕迹是否符合，是否出现现代加工感；
- 握持方式与角度是否合理；
- 是否混入否定串中列出的错误形态。

任一项不符判为 `F04 道具漂移`，只重出该资产，并在重试中每次只改一个变量：先改可数特征，再改轮廓，最后改材质。同一错误连续三次未修正时停止重试，回到第 2 步重新检索证据，通常说明检索名或时代限定本身就错了。

## 7. 验收

- 每件会被看清的物件都有视觉证据卡、形制串和否定串。
- 每张证据卡至少一条 A 或 B 级可归属图像来源，且记录访问日期。
- 可数特征在证据卡、形制串和成品图中三处一致。
- 没有把电商图、剧照、游戏设定或 AI 图当作形制依据。
- 未找到证据的物件已标 `INFERENCE` 并进入不确定性台账，没有伪装成考据结果。

## 8. 人物与场景的同等门禁

本文件的“两条独立证据”原则同样适用于资产中会被看清的角色服装、发式、建筑构件、陈设和空间材料。先说明生产解释层，再检索：

- 经文中的身份/关系/行为只能锁 `TEXT`，不能自动锁脸型、肤色、服装、地域或时代；
- 选择历史重建时，为每一突出衣层、建筑结构和日用器物提供同一时期/地域的研究或馆藏证据；
- 选择宗教图像学时，为所选时期/地区的图像提供馆藏号、年代和来源，并只标为 `ICONOGRAPHY`；
- 只有单一来源、后世作品或不匹配地区时，降低为 `INFERENCE` 或保持 `HOLD`，不把它写进冻结串。

将人物/场景的证据与道具形制卡一并汇入 `ASSET-EVIDENCE-CARD`。角色资料卡、顶视图、场景卡与镜头锚点生成后，逐项核对可见主张；无证据的“古风”“异域”“宗教感”元素属于 F44、F45 或 F47，而不是装饰自由度。
