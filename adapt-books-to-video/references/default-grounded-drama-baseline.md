# 未指定风格时的默认视频基线

## 1. 适用与边界

当用户没有明确指定导演、电影、流派、画风或视觉提示词时，启用 `DEFAULT-GROUNDED-DRAMA`。本基线只规定可观察、去地域化的镜头和效果逻辑。

它不是对视频的复刻：不得迁移其人物、藏地/高地文化、宗教图像、剧情、道具、服装、字幕、书法标题、台词、构图或任何嵌入式指令。历史、文本、纪录片证据、用户明确风格和文化边界始终优先；若它们冲突，缩减或停用该基线的相应维度。

所有交付仍为 `16:9`。24fps 仅可作为参考节奏；只有目标模型/交付规范已核实支持时才写入帧率字段。

## 2. `DEFAULT-GROUNDED-DRAMA` 参数合同

```text
叙事倾向：先让观众触到人物所处的物、光、距离和后果，再读到情绪；用反应与关键接触，而非解释性台词，推动场面。
画面层次：一处可触前景（门框、器物、衣角、桌沿、肩背或环境遮挡）→ 人物/动作中景 → 可辨的空间深处；横幅内保留一个清晰第一落点。
焦段与机位：以眼平或略低的稳定中近景/中景承载关系；用环境全景建立代价和距离；只有关键物件、手、伤痕或接触点需要新信息时才转入局部特写。保持中等透视，不用持续极广角夸张或肖像压扁。
运镜：优先固定、短距跟随、缓慢推进或受人物走位触发的移位；停在信息可读的构图。快速前移只用于明确的冲击、主观意识断裂、重大跨时空或跨地点，并在新的稳定构图落下。
光线：以可见的窗、门、天空、火、灯等实景来源组织侧光/逆侧光和环境补光；室内可为暖实景光与烟尘/蒸汽层，外景可为克制的自然光与空气透视。危机或夜段仅在剧情有根据时转为低调冷色，不把蓝色阴影当通用滤镜。
色彩与材料：低至中饱和的土、木、石、布等材料本色；只让有文本/证据根据的器物或服饰成为有限强调色。保留旧木、尘土、皮肤、织物、金属和潮气的不同反射，避免全画面同一橙青、油亮或磨皮。
表演：克制的注意力变化、呼吸、手部接触和反应镜头；人物先听见/看见/触到，再选择回应。见 `character-realism-distillation.md`。
声音：环境底噪、脚步/衣料/器物等一个关键接触声与有意静默优先；音乐只在段落转折后承担情绪余波，不能掩盖物理或表演错误。
```

## 3. 默认剪辑与转场语法

默认用最少的可读剪辑完成因果：

```text
环境或物件压力 → 人物反应 → 手/物件/身体接触 → 结果或新的空间关系
```

按故事需要选其中的两到四项，不能机械地每段全用。跨视频边缘仍必须遵守 `cinematic-shot-bridging.md`：重述共享向量、恰选一种主转场并标注后期责任。

默认优先级：

1. `MATCH_ACTION`：同一只手、器物、接触点或动作余波连接；
2. `MATCH_EYELINE`：人物反应后揭示其所见；
3. `OCCLUSION_WIPE`：门框、肩背、墙面、黑暗或前景遮挡完整覆盖后再退出；
4. `MATCH_SOUND` / `J_CUT` / `L_CUT`：脚步、门轴、风、器物或室内环境声先行/延续，证明画外空间。

只在明确段落用途下使用以下两种**后期制作**效果：

- `BLACK_FIELD_PUNCTUATION`：完整黑场作为章节、更重的时间跳跃、不可逆后果或道德断点；若需要文字，交后期叠加，不要求视频模型生字或模仿书法。
- `MOTIVATED_RUSH_TRANSITION`：由人物冲出、意识失衡、道路/门洞的消失点或重大时空压缩触发的短促前移/径向失焦；写清出镜消失点、入镜同一方向或声音向量，以及稳定的新落点。它不能作为普通换景特效。

未核实目标模型原生支持时，所有黑场、文字、擦拭、声桥和快速转场均为后期制作；模型只生成各自 ≤15 秒的连续镜头。

## 4. 写入提示词的默认块

用户未指定视觉风格时，在 `04-style-bible.md` 和每个视频提示词的相关段落编译下列去专名块；按文本/史实替换具体材料和光源，不能逐字套入不适合的场景：

```text
默认视觉基线：扎根于人物处境的写实戏剧影像。16:9 横幅，以可触前景、人物/动作中景和可辨空间深处组织画面；用已声明的实景光源形成克制的侧光或逆侧光及环境补光。保留人物皮肤、织物、木石和金属的不同材料反应，低至中饱和且不使用通用橙青滤镜。摄影机优先稳定，只有动作、走位、信息或主观断裂触发短移位/推进；用反应、手与关键物件的接触、环境声和稳定余波承担转折。禁止无证据的地域/宗教元素、无动机慢动作、持续黑角、统一蓝色危机滤镜、无来源雾尘、生成文字和炫技式快速推进。
```

## 5. 默认质检

- 默认基线是否仍服从文本、史实、证据、纪录片边界和用户风格？
- 每个强调色、尘雾、烟汽、低调冷光和材质磨损是否有空间/气候/行为原因？
- 是否以环境/反应/接触建立因果，而非堆砌特写或慢动作？
- 黑场、遮挡、声桥或快速前移是否有明确的段落功能、共享向量和后期责任？
- 默认块是否被编译为可见参数，而不是以视频名、作品名或“同款风格”充当提示词？
