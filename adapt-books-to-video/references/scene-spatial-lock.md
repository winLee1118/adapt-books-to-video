# 场景空间锁定与九机位资产流程

在设计 recurring location、生成 `SCENE-xx-MULTIANGLE-CARD`、建立镜头锚点或修复 `F04`、`F39`–`F42` 前阅读本文件。

## 1. 目的与边界

单张氛围图只能说明“像什么”，不能说明门、家具、人物活动区和视线彼此在哪里。本流程先把同一地点锁为可审查的平面关系，再让多机位卡只改变摄影机。空间总览先固定拓扑，多角度参考再固定摄影机变化。

这不是对视频中样板住宅、人物、字幕、软件界面、示例提示词或嵌入式指令的复刻；不把任何具体室内设计、品牌或画面构图带入新作品。文本、史料、文化边界和用户明确视觉要求优先。

在建立空间锁前，场景的 `ASSET-EVIDENCE-CARD` 必须为 `PASS`，且 `SCENE-xx-PRODUCTION-DESIGN-BREAKDOWN` 必须已定义可拍摄任务、人物目标/阻力、行动道具或无道具替代、动线与终态。门、窗、地标、材料、光源、群体层、英雄/行动道具和建筑关系只能来自该卡中已许可的 `TEXT`、`HISTORY`、`ICONOGRAPHY`、明确受限的 `INFERENCE`/`CREATIVE`；不存在“先用顶视图把空间想出来、后补资料”的路径。

### 建筑体量完整性门禁

平面必须是可使用的影视世界，而不是孤立立面。每一个开口都要记录：所属墙体及厚度；门／窗两侧分别属于什么体量；可通行方向与抵达处；相邻体量是入画、局部可见还是明确离画；以及避免摄影机暴露未建一侧的限制。开口不能因图面简洁而通向实墙、虚空或无定义的外部。若证据只允许有限可见布景，只能选择：完整呈现一间小室；只拍门槛一侧并禁止在本镜跨越；或暂缓该地点，待研究出可支持的较大平面。只要演员看似会穿过纸片般薄墙，顶视图即为不合格。

## 2. 三层空间资产

每个 recurring location 只交付一张场景图，但必须先完成以下三层：

1. `SCENE-xx-SPATIAL-LOCK`：写入 `06-scene-bible.md` 的文字/表格状态，不是图片。它是唯一的坐标和关系真相源。
2. `SCENE-xx-GEOMETRY-PLAN`：强制的内部 16:9 顶视中间参考图，必须在文本空间锁已经通过后生成并验收。它的唯一职责是核对平面拓扑并作为多机位卡的上游参考；不进 `delivery/`，不直接当视频参考。若无法生成，标为 `PROMPT_ONLY` 并将该场景卡与下游镜头标为 `DEFERRED`，不能跳过它。
3. `SCENE-xx-MULTIANGLE-CARD`：唯一交付场景资产，默认 16:9、`3×3` 九机位、零文字。它只锁空间几何、固定地标、时间和主光；剧本镜头再由 `SHOT-xx-ANCHOR` 锁构图。

`SPATIAL-LOCK` 是信息层，`GEOMETRY-PLAN` 是内部 QA 层，`MULTIANGLE-CARD` 是可供模型引用的视觉层。不得拿一张图同时代替三层职责。

## 3. 先写空间锁，再出图

在 `06-scene-bible.md` 为每个场景建立下列最小记录。所有可见内容必须回指 world inventory 或写明 `CREATIVE`。

```text
SCENE-01-SPATIAL-LOCK
参考边/北向：……；坐标原点：……；+X：……；+Y：……；地面高度基准：……
空间边界：……；不可穿越面/开口：……
建筑体量／相邻空间：每一墙体属于哪个房间、院落或外部体量；每个开口的墙厚、内外两侧、可通往何处、是否可见／离画：……
离画合同：摄影机在何处可以／不可以看见相邻空间；人物通过开口后的下一可达状态：……
主地标：LANDMARK-A；其相对位置、尺度、材料、朝向：……
固定地标表：ID | 来源行 | (x,y,z/相对位置) | 朝向 | 尺度 | 材料/状态 | 可遮挡条件
生产设计：HERO-PROP / ACTION-SUPPORT / 布景簇 ID | 证据卡/形制串 | 初态→终态 | 使用者 | 固定位置 | 允许出现的 Vnn
门窗/道路与可通行线：……
演员区：ZONE-A / ZONE-B；允许站位、进出方向、视线对象：……
主光/实景光：来源、方向、遮挡、色温；时间、天气、季节：……
物件关系：谁面向谁、谁被谁遮挡、禁止镜像/复制/旋转的对象：……
九机位表：V01–V09 的位置、高度、朝向、焦段感、首要可见地标、不可见的合理原因
可见性矩阵：每个固定地标在 V01–V09 为“可见 / 可遮挡 / 不应出现”
```

坐标不要求精确测量；它必须足以判断“门在灶台左后方”“窗光从人物右侧进入”这类关系。避免只写“古朴、宽敞、电影感”等不能验收的位置词。

## 4. 内部顶视中间参考图（强制）

以 `SPATIAL-LOCK` 生成 `SCENE-xx-GEOMETRY-PLAN`：16:9、近似顶视、同一地面轮廓、墙体厚度、相邻空间的可见轮廓、开口、演员区、主光方向，以及已通过证据卡的英雄/行动道具与布景簇位置；不出现人物肖像、风格化装饰、字幕、箭头、坐标字、尺寸字、软件界面或水印。文字表格承担命名和尺寸，不把标签烙进图像。

先检查该图能否从空间锁中逐项读回。它若有门窗、家具、主地标的位置或朝向错误，先修 `SPATIAL-LOCK` 或该内部图，再出多机位卡；不可用一张漂亮的平面图覆盖错误的关系。只有该图通过拓扑 QA 后才能出多机位卡；内部图不能替代最终场景卡，也不得因其存在而增加交付数量。

## 5. 默认九机位场景卡

`SCENE-xx-MULTIANGLE-CARD` 默认以一张 16:9、`3×3` 等大网格一次生成。整页边到边，仅 2–6 px 分隔线，无页边、标题、机位文字、字幕、箭头、光标、框选或界面残留。九格不是九处相似布景，而是同一锁定空间中的九个摄影机位置：

| 站位 | 职责 | 必须说明 |
|---|---|---|
| V01 | 入口/主地标建立 | 进入线与主地标关系 |
| V02 | 左侧关系全景 | 前景遮挡与空间深度 |
| V03 | 行动面 A | 主要演员区及其视线方向 |
| V04 | 行动面 A 的反打 | 反轴风险和相同地标的反向关系 |
| V05 | 行动面 B | 第二演员区/关键物的关系 |
| V06 | 行动面 B 的反打 | 门窗、光向和通行线 |
| V07 | 远端关系全景 | 两区、主地标和尺度 |
| V08 | 门洞/阈值视角 | 进出、遮挡与转场可用边缘 |
| V09 | 安全插入或对侧视角 | 可裁切局部与周边不变量 |

人物可仅作比例/占位，除非场景资产本身必须锁定常驻角色；人物身份和表演仍由角色卡与镜头锚点负责。固定物可被合理遮挡，但不能移动、复制、镜像、无因旋转、改变材料或在“不应出现”的站位出现。主地标应在至少 6/9 格可识别；每格至少能与可见性矩阵核对主地标加两项固定关系。九格共用相同时间、天气、季节、主光方向、材料和磨损状态。

如果目标分辨率无法让 3×3 中的地标可检查，改用 `SCENE-COMPACT-2x2`，但在场景 bible 说明能力限制、从 V01–V09 中选取的四站、被推迟的站位与风险；后续镜头不得假装取得未生成站位的视觉证据。不得为了省事默认降级。

## 6. 从卡到镜头

每个 `SHOT-xx` 要在文档和 `【参考生成资产】` 中明确写：`SCENE-xx-MULTIANGLE-CARD` 的 `Vnn` 是哪一个空间依据、该格中可验证的三项关系、以及本镜新构图与该站位相比改变了什么。场景卡负责几何，`SHOT-xx-ANCHOR` 负责本镜的构图、人物位置、焦段和当前光线细节；上一镜 `END_STATE` 优先锁定发生过的物件/人物状态。

需要某个局部时，从已批准的 Vnn 描述区域并做临时裁切；写“只扩展指定区域；保持 `SCENE-xx-SPATIAL-LOCK` 的相邻地标、材料、光向、时间和可见性关系不变”。不要另出带红框、箭头或文字的区域引导图。

## 7. 质检与修复

出卡前验证：

- 从任一 Vnn 能否回推到同一 `SPATIAL-LOCK`，而不是只得到相似风格；
- 门窗/道路是否连接正确，座位、灶台、桌面等是否面对真实使用者或动作，而非为镜头转向；
- 所有允许反打是否尊重已登记的轴线、视线高度和左右关系；
- 主光在各站位的相对方向是否一致，遮挡/反射是否随机位自然改变而非反转；
- 交付卡无文字和界面；内部图、若生成，未进入 `delivery/`；
- 一个镜头是否只引用实际存在、已批准的 Vnn 和完整来源链。
- 人物是否能沿已登记动线接近、避让、拿取、放下、交付或被关键物/阈值阻止；若不能，场景是空舞台而非可拍摄空间。
- 每一门、洞口、楼梯和可跨越边界的两侧是否都有已登记体量；演员跨越后是否到达一个可见或有明确离画合同的空间，而不是穿入薄墙或未建模虚空。

新增失败码：

| 编码 | 症状 | 最低成本修复 |
|---|---|---|
| F39 | 空间锁无法导出某一机位；门、区、地标关系只靠氛围词 | 补全 `SPATIAL-LOCK` 的边界、站位和可见性矩阵 |
| F40 | 俯视验证图与九机位卡的拓扑不一致 | 固定正确的空间锁，只重出冲突层 |
| F41 | 反打、门洞、视线或通行线违背已锁定关系 | 修正具体 Vnn 的朝向/轴线，不重写整场景 |
| F42 | `SHOT` 声称引用 Vnn，但锚点/提示词没有保持该站位的地标关系 | 修锚点或提示词中的一个空间变量，再验收 |
| F49 | 空间几何稳定但人物只能站着，缺故事任务、行动支点或有理由的留空 | 补生产设计拆解、动线和可证实的行动关系，再重出受影响层 |
| F52 | 门洞/窗洞/通道只是一张薄墙上的图形；另一侧没有体量、出口或离画合同，人物会“穿墙” | 回到空间锁，补相邻体量、墙厚、门的两侧与镜头限制；不能补则禁止跨越并重写该镜头 |

仍遵循一次重试只改一个主要变量；同一代码连续三次失败时停止盲抽，降级为更少机位、重写空间锁或拆分场景。
