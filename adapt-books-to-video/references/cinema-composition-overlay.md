# 21:9 三帧导演构图预演层

## 1. 边界

这是用户要求的中间生成步骤，不是交付资产、更不是视频参考资产。它只在一个 `SEQ-ID` 的导演设计、相关角色/场景/道具证据卡和最终可用资产均已通过后运行。

每个序列生成且只生成三张独立 `21:9` 横幅：`PREVIS-SEQ-xx-01`、`PREVIS-SEQ-xx-02`、`PREVIS-SEQ-xx-03`。不要把三张画在一个画布、拼成海报、添加片名/字幕/序号/边框，也不要将其中任何一张上传给最终图像或视频模型。所有最终卡、分镜、提示词和视频仍为 `16:9`，其资产数量合同不变。

`PREVIS` 的唯一产出是可文字化的导演决定：观看位置、构图压力、视线流量、色彩命题、实拍成像限制和反模板化排除项。将这些字段写回 `22-composition-triptychs.md`、`20-director-design.md`、`07-storyboards.md` 和 `08-video-prompts.md`；不要把预演图本身写入 `【参考生成资产】`。

## 2. 前置条件与引用

每个预演图的提示词仍为中文，并带完整 `【参考生成资产】` 块，只能引用已批准的 `CHAR`、`SCENE`、`PROP`、`STYLE-COLOR` 资产：

- `IDENTITY` 只锁身份和服装层次；
- `SCENE_GEOMETRY` 只锁场景坐标、地标、时间和主光方向；
- `PROP_FORM` 只锁经过证据门禁的形制；
- `COLOR_MATERIAL` 只锁已批准的材料和色彩；
- 不得借预演图补写任何人物相貌、史料道具、建筑、时代、宗教图像或模型能力。

为每张预演图在台账登记 `origin: INTERNAL_PREVIS`、`reference_role: PREVISUALIZATION_ONLY`、`status: GENERATED` 或 `PROMPT_ONLY`、`file_path: process/cinema-triptychs/...`，并写明“不得作为最终生成或视频模型输入”。

## 3. 三帧合同

三张图必须来自同一 `SEQ-ID` 的同一戏剧问题和同一证据边界，但各自承担不同的观看决策。它们不是固定的远—中—近模板，也不是可剪辑的连续镜头。

每张先填写：

```text
PREVIS-ID | SEQ-ID | SCRIPT-BEAT-ID 覆盖范围 | 上游资产与证据卡
未解决状态：人物/调查此刻无法立即解决什么
观众位置：同处现场 / 被困于边界 / 观察者一侧 / 被观察者一侧 / 反射或设备内部等
构图压力：被观察 / 被困住 / 关系疏离 / 权力不对等 / 心理失衡 / 事后状态 / 感官插入
视线流量：从 A 进入，被 B 阻断或减速，落到 C，最后由 D 带走
未解释信息：边缘、遮挡、反射、失焦或画外空间中的哪一项可见事实
色彩命题：主色/辅色/点睛色及其场景内来源
成像限制：摄影机可站位置、焦段感、实际光源、真实材料与受限光学
主要动作与次要线索：各一项，均可从已批准事实追溯
反模板排除：本帧不允许的构图/光效/摆拍/CG 化倾向
```

三帧组至少在四项上发生有理由的差异：观看位置、景别、机位高度、人物—空间比例、主要构图压力、信息密度、焦点层、光线集中处或人物状态。不得让三张都成为人物居中站立、同一种门框遮挡、同一种人物背影、同一种汗水/手部特写或三段相似的广角空间。

## 4. 预演提示词编译

按下列顺序编写每张中文提示词：

1. `21:9` 独立横幅预演图、`PREVIS-ID`、同一 `SEQ-ID` 和“不含文字/不含拼贴”；
2. 经门禁允许的具体时间、空间、人物和未解决状态；
3. 一个主要动作与一个次要线索；
4. 观众位置、摄影机实际站位、景别/焦段感和一个主要构图压力；
5. 完整视线流量与未解释信息；
6. 可见实景光源、色彩命题的物质来源、真实材料、有限景深/高光/边缘成像；
7. 负向约束：无概念设定图、游戏主视觉、广告摆拍、塑料皮肤、无来源轮廓光、青橙默认调色、HDR 锐利背景、粒子/烟雾堆砌、电视剧式正反打、文字、海报排版、三联拼贴。

不要使用“高级、史诗、电影感、masterpiece、cinematic”等词替代可检查决定。历史、神话和宗教题材尤其不得以宏大场景、超人姿态或特效代替文本和证据已支持的具体行动。

## 5. 检查、选择与回写

生成后逐张检查：

1. 是否仍保持上游身份、场景、道具、时代和光线的冻结字段；
2. 摄影机是否有现实可站位置，前景/遮挡是否说明了空间、窥视、距离或危险；
3. 视线流量能否逐段指出，且没有变成元素堆叠；
4. 色彩是否来自场景内部，而不是滤镜；
5. 是否出现 CG 概念图、广告图、游戏主视觉、偶像/电视剧摆拍、塑料材质、无意义雾粒或套模板三联；
6. 三张差异是否来自事件与观看关系，而不是任意换景。

写一条 `PREVIS-DECISION-SEQ-xx`：选择每张中可采用的字段，或明确“无图可采用，仅依导演设计文本”。回写时只转抄字段，不复制图片构图的可识别细节。失败分别记录：`F60`（视线流量不可读）、`F61`（构图模板重复）、`F62`（CG/广告/电视剧化）、`F63`（预演图被误用为最终或视频参考）。每次重试只改变一个主要决定。

## 6. 不可用情形

当序列没有已通过的空间/身份资产、历史证据仍为 `HOLD`、用户仅要求快速文本提案、或没有图像生成能力时，不得伪造预演结果。前三种情况标记 `DEFERRED`；最后一种写三条 `PROMPT_ONLY` 预演提示词和文字 `PREVIS-DECISION`。无论何种情形，都不得让预演阶段改变最终交付图片数量。

## 7. 16:9 构图复核

在正式锚点记录 PREVIS-DECISION → 16:9 的采用结果：两侧人物/道具有无被裁掉、主要视线落点、前中后景比例、动作空间、负空间和反打轴是否仍成立。复核必须看实际16:9锚点；未生成写 PENDING。失败改正式构图，不把21:9图裁切/扩图后当最终参考。普通正反打可有叙事价值，反模板检查针对机械重复，不把所有正反打一概禁止。
