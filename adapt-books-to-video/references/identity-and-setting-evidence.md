# 身份与场景证据协议：原文术语 → 研究 → 可生成资产

当人物或场景带有种姓、民族、宗教、地域、阶层、时代或其他具文化含义的名称时，在任何角色卡、场景卡、镜头锚点或视频生成前阅读本文件。

## 1. 原则

- 原文中的身份词只证明原文所说的身份、关系或行动；它不是人体测量、肤色、脸型、服装、居所或道德特征的证据。
- 不把种姓或族群理解为单一生物表型。不得用殖民时期“种族类型”描述、影视惯例、AI 图或现代刻板印象作为脸部／肤色依据。
- 先选故事的生产解释时空，再找该时空的可归属物质文化证据。没有选择时空，就不能声称角色或场景是历史写实。
- 角色的具体面容只能来自有授权的真人参考、用户提供的角色设计，或透明标注的 `CASTING_CHOICE`。它只锁定连续性，绝不代表该身份群体。

## 2. 必填研究记录：`IDENTITY-TO-ASSET-RESEARCH`

在 `02-research-dossier.md` 中为每一个主要人物／场景建立下表；未完成即为 `HOLD`。

| 字段 | 必填内容 |
|---|---|
| 研究 ID | 例如 `ITAR-CHAR-01` |
| 原文术语 | 原文、译名、精确定位；区分叙事身份和可见描述 |
| 术语研究 | 至少一项 Tier A/B 词典、校勘、学术研究或权威机构来源；说明其历史语义与不适用的现代含义 |
| 叙事时空 | 文本能确定的地点／时间；不能确定时必须明确写“未定” |
| 选定生产时空 | 地区、日期范围、聚落／建筑类型、社会物质层；若未选择，资产 `HOLD` |
| 角色物质文化 | 每一可见服装层、发式、鞋履、首饰、可见器物的来源；有形制的项目至少两项独立可归属图像／实物证据 |
| 场景物质文化 | 建筑、平面、门窗、家具、器物、照明的来源与适用范围；文本只支持地点名时不得补出平面 |
| 表型与选角 | `TEXT` 支持的身体描述；若无，写“无文本／历史表型依据”。具体脸与肤色必须标 `CASTING_CHOICE`，并注明不代表群体 |
| 冲突／空缺 | 竞争解释、被拒绝方案、证据不足项及其 `HOLD` 后果 |
| 下游允许项 | 可以进入 AEC 的具体可见主张；其余全部禁止 |

## 3. 角色证据门

角色卡只有同时满足以下条件才可 `PASS`：

1. 原文人物和行为有精确定位；
2. 已选地区和日期范围，或用户明确要求非历史、非地域的抽象方案；
3. 每一可辨服装／饰物／发式要么有对应研究证据，要么从画面移除；
4. 肤色、脸型等有个体文本描述，或透明标为 `CASTING_CHOICE`；不得标为群体固有特征；
5. 每个历史物件或服装形制有两个独立、可归属的视觉证据，并记录其不支持的范围。

未选时空时，唯一可通过的替代方案是用户明确选择的抽象／非民族化风格，并在资产和提示词中写出 `CREATIVE`。不能把这个替代方案称为特定地域或身份群体的历史写实。

## 4. 场景证据门

文本中的“家”“寺”“塔”“城”等只建立地点功能。要生成历史写实场景，必须先有选定地区／日期和与之匹配的建筑、家具、照明证据。没有可靠平面时，可采用最少、可删除、明确 `INFERENCE` 的空间功能布局；若用户要求历史还原，则必须保持 `HOLD`，不以氛围词或模型默认“古风”代替研究。

## 5. 审核输出

每次交付需报告：`ITAR` 状态、选定时空、可见主张的来源数、`CASTING_CHOICE` 项、禁止推导项、`HOLD` 的下游资产和失败码。任何未满足的历史写实资产保持 `DEFERRED`，不以“创作自由”改写为通过。
