## 1. 使用边界

把导演或经典电影当作分析索引，不当作可直接复制的画面指令。不得复制具体镜头、角色、台词、剧情、布景或可识别构图。最终提交给生成模型的中文提示词优先使用可观察参数，不依赖“某某导演风格”几个字。

若用户点名在世创作者，采用“高层方法拆解”模式：说明叙事、构图、镜头、光线、色彩、剪辑、声音和表演特征，然后生成原创组合。若模型可能屏蔽导演或电影名称，分析档案保留名称，模型提示词删除名称。

历史考据优先级始终高于风格覆盖。导演镜头不得引入错误朝代服饰、现代建筑、错误宗教图像或不符合文本的行为。

## 2. 参数合同

每个项目只启用一个主覆盖层。记录：

```yaml
style_profile_id: STYLE-PROFILE-xx
analysis_reference: "导演、电影或流派名称；只用于分析"
narrative_bias: "叙事倾向"
lens_set_mm: [24, 35, 50, 85]
shot_size_bias: "偏好的景别"
composition: ["构图规则"]
camera_moves_allowed: ["允许的运镜及触发条件"]
camera_moves_avoid: ["不适合的运镜"]
motion_budget: "低/中/高，并说明人物与摄影机如何分配"
lighting: "光源、方向、硬软、光比"
palette: ["主色", "辅色", "强调色"]
texture: "胶片/数字、颗粒、高光、黑位、材质响应"
editing_rhythm: "平均镜头长度、停顿、转场倾向"
sound_policy: "环境、拟音、音乐、静默"
performance_register: "表演强度和身体规则"
aspect_rewrite_16_9: "横幅构图"
negative_additions: ["该方法特有的排除项"]
```

覆盖优先级：`历史/文本/证据硬约束 > 用户明确要求 > 主风格覆盖 > 类型片默认 > DEFAULT-GROUNDED-DRAMA > 通用摄影默认`。

## 3. 预设方法镜头

以下名称只用于选择方法。模型提示词应展开右侧参数。

| 方法索引 | 可迁移方法 | 避免误解 |
|---|---|---|
| 希区柯克式悬念 | 观众比人物多知道一项信息；窥视机位；延迟揭示；关键物件特写 | 不是突然惊吓和任意荷兰角 |
| 库布里克式形式控制 | 广角单点透视；人物被建筑秩序压迫；中央对称；缓慢正向推进 | 不等于所有画面居中或冷蓝色 |
| 黑泽明式动态空间 | 天气作为压力；前中后景均有动作；群像按方向分层；动作轴线清楚 | 不等于只加暴雨或武士元素 |
| 小津式低机位观察 | 接近坐姿视线的静态低机位；门框层次；日常物件空镜；克制省略 | 不等于摄影机贴地或人物毫无动作 |
| 伯格曼式心理特写 | 面部与沉默承担冲突；有限空间；高对比黑白或低彩；呼吸可听 | 不等于持续哭泣和夸张凝视 |
| 费里尼式梦境群像 | 仪式性队列、夸张但有人味的人群、现实与记忆滑移 | 不等于随机怪诞道具堆砌 |
| 塔可夫斯基式诗性时间 | 长时段观察；水、火、风与反射形成时间感；缓慢横移或静止 | 不等于无因果慢动作或空洞哲学旁白 |
| 塞尔乔·莱昂内式对峙 | 极远景建立距离；眼、手、道具极近特写；等待后突然行动；声音先行 | 不等于套用西部服饰和沙漠 |
| 王家卫式碎片记忆 | 狭窄框中框、实用霓虹、错过与延迟、短暂抽帧感、主观旁白 | 不等于全片紫蓝霓虹或无动机手持 |
| 张艺谋式色彩仪式 | 单一主色场、群体运动形成图案、民俗材料与空间秩序 | 色彩必须服从史料，不能把不同地区民俗混用 |
| 斯皮尔伯格式情感揭示 | 先拍人物反应再揭示对象；调度清晰；家庭/群体关系驱动奇观 | 不等于逆光和推镜的机械组合 |
| 芬奇式程序控制 | 精确稳定机位；运镜只响应信息变化；受控低饱和色；程序性动作 | 不等于所有画面青黄或人物完全无情绪 |
| 维伦纽瓦式尺度压力 | 人物在巨构中的比例；雾尘分层；几何空间；低频声音与留白 | 不等于盲目扩大建筑或橙蓝调色 |
| 侯孝贤式远距观察 | 固定远景、门窗纵深、真实时间、画外空间和省略 | 不等于把关键动作拍得不可读 |
| 黑色电影 | 高反差黑白、百叶影、主观不可靠信息、潮湿街道和局部实景光 | 不是必须侦探、礼帽和香烟 |
| 德国表现主义 | 倾斜几何、硬阴影、心理空间外化、受限色彩 | 不能破坏真实历史空间，除非明确采用舞台化诠释 |
| 意大利新现实主义 | 自然光、真实环境、普通劳动、非炫技摄影、物质细节 | 不等于低画质或缺乏构图 |
| 法国新浪潮 | 跳切、街头自然光、主观旁白、观看摄影机的自觉 | 跳切必须服务观点，不能用于掩盖连续性错误 |

## 4. 经典电影与流派转换

用户给出经典电影时，先生成“去专名转换表”：

```text
参考名称（分析用）
可观察构图
焦段与机位
光源与光比
主辅色及材质响应
摄影机运动及触发原因
剪辑/停顿
声音与表演
不可复制元素：具体人物、服装、道具、布景、台词、镜头复刻
适配本书的方法：保留什么、因历史/文本约束拒绝什么
```

例如“未来黑色电影”不得直接变成某部影片的场景复刻，而应转换为：巨构压迫比例、冷色阴影与局部暖实景光、雾尘体积层次、缓慢移动、低频环境声、克制表演等可迁移参数，再与本书时代材料结合。

## 5. 选择与冲突规则

- 用户没有点名风格时，启用 `default-grounded-drama-baseline.md` 的 `DEFAULT-GROUNDED-DRAMA`，并根据主题缩减其参数；它是去专名的默认制作基线，不是导演覆盖，也不能引入视频来源的地域、宗教、人物、文字或剧情。
- 用户点名多个导演/电影时，不平均混合。选一个主覆盖层，最多从另一个借一个明确维度，例如只借声音策略。
- 同一维度冲突时必须做选择：静态远距观察与高频手持不能同时作为主摄影语法。
- 风格不能改变角色身份、史料服装、场景坐标和文本因果。
- 所有输出固定为 `16:9` 横幅；将横向队列、门框、人物关系与动作方向排入可读的横幅层次，不能用裁切或另建竖幅方案规避构图问题。
- 每个覆盖层都要生成一条“这不是什么”，防止相邻风格混淆。

## 6. 输出格式

在 `04-style-bible.md` 增加：

1. 分析参考名称与使用边界；
2. 完整参数合同；
3. 去专名中文模型提示词块；
4. `16:9` 横幅构图与第一落点；
5. 与历史/文本的冲突及处理；
6. 同一控制场景的“无覆盖版/覆盖版”差异；
7. 风格专属负向约束。

质量报告必须确认最终模型提示词没有依赖导演名或电影名才能成立。
