# 生产类型与真人中式神话故事片

在用户要求故事片、纪录片，或明确要求真人中式神话故事片时阅读本页。它只改变已选项目的影视化路径；不改变文本、历史与图像学证据的层级。

## 1. 先锁生产类型

在 `00-brief.md` 写入且只选一个主类型：

| `production_type` | 适用结果 | 资产原则 |
|---|---|---|
| `DOCUMENTARY` | 论证、档案、采访或明确标注的重建 | 历史可见主张必须有证据；神话画面作为解释性重建标注。 |
| `STORY_FILM` | 普通叙事故事片 | 角色和场景由文本事实加已标注的创作选择构成。 |
| `LIVE_ACTION_CHINESE_MYTHIC_STORY_FILM` | 真人出演、采用中式神话电影的图像与空间语法 | 每个主资产同时有“真人表演锚点”与“神话图像学层”。 |

“中式”是制作选择，不是对原故事发生地、人物族群或历史年代的断言。将其写为 `PRODUCTION_INTERPRETATION`；文本中的地域/身份仍按原文保留，任何跨文化转译都标为 `CREATIVE` 或 `ICONOGRAPHY`。

## 2. `LIVE_ACTION_CHINESE_MYTHIC_STORY_FILM` 的世界卡

在首张角色或场景卡前建立 `MYTHIC-WORLD-CARD`，至少锁定：

- **现实基座：**真人演员的脸、骨相、年龄感、呼吸、布料重量、地面接触和可解释光源；神祇不是蜡像、雕像或纯 CG 角色。
- **神话层：**该世界只用 2–4 种可反复辨认的图像语法，例如低强度圆形光轮/背光、云海层、玉石/鎏金/丝帛的受光、莲座/云台、香烟或天光形成的纵深；逐项标为 `ICONOGRAPHY` 或 `CREATIVE` 并说明来源。
- **中式电影转译：**以层叠云台、深色木构、褪赭石阶、丝幡、青灰山影、琥珀灯火、玉白反射等**经过选择**的视觉元素组织空间。选择的元素要有来源或明确 `CREATIVE`；不把“中式”变成历史朝代、地域、民族表型或建筑考据结论。
- **叙事功能：**每个神话元素须服务人物关系、阈限、选择、信息揭示或转场，不能只作装饰。
- **强度合同：**神话元素以可读、克制、可持续复用的低/中强度出现；除非剧情明确要求，避免用爆发性特效替代演员选择。

### 图像学传统选择

当用户指定犍陀罗、秣菟罗、敦煌等佛教图像传统时，在 `MYTHIC-WORLD-CARD` 另锁 `iconographic_tradition`。它可与“中式神话故事片”的制作语言并存：前者控制角色/道具的图像学形制，后者控制空间、光色和叙事节奏。

例如 `GANDHARA_BUDDHA` 的资产在经过至少两条可归属馆藏资料核验后，可采用经来源支持的波浪状发束汇入肉髻、长耳垂、宽厚袈裟垂褶、灰片岩般的低反射材质、光背与坐/立佛的手势关系。每个具体选择都要写明它来自哪一件已选藏品；不要把不同藏品的细节无记录地拼成“唯一正确”的佛陀。演员的脸仍是 `CASTING_CHOICE`，绝不由犍陀罗、希腊化影响、地域或宗教身份推导族群、五官、肤色或真人容貌。

## 3. 角色：真人锚点 + 神话标记

对佛、菩萨、神祇、鬼王、罗汉等重要角色，角色卡不得只是一张中性现实僧人/演员资料照，也不得变成不可表演的概念图。每张卡要锁两层：

1. **真人锚点：**同一可演的脸、身体比例、自然皮肤纹理、明确服装结构、站姿/坐姿、目光、呼吸和手部习惯。
2. **神话标记：**一项身份可读的光/材质/空间关系，且在资料卡、表情卡和剧情锚帧中保持一致。神话标记须由已选图像传统与证据支持，转换为可观察的光源、材质和空间参数。它必须保留人物的面部阴影和布料重量，不把脸抹成平面金像。

资料卡的背景允许是受控的**神话肖像空间**，不必是纯棚拍灰底；但三视图区仍须清晰检查正/侧/背的身体与服装连续性。表情卡保留同一光学身份，只使神话光场停留在低强度背景层，不能让光效吞没表演。

## 4. 场景：可拍摄的中式神话空间

每个神话场景的 `SCENE-PRODUCTION-DESIGN-BREAKDOWN` 除普通空间合同外，还要写：

- **神话主地标：**云台、莲座、天阶、塔寺、业海水岸、木构礼拜轴、丝幡或玉白天光中选一项，并说明其文本/图像学/创作层级。
- **可达性：**地标必须是能站、走、绕、触或被镜头横越的三维空间；神话云雾不能遮成没有厚度的虚空。
- **材质/光的因果：**石阶受天光、丝幡受风、玉白/金属/水面受反射，角色皮肤和衣料与场景共用同一主光。
- **中国神话电影的空间节奏：**以台阶、门槛、云层、幡幕、山影或水岸组织前中后景和人物路径，避免把主体孤立在无功能的空平台。

## 5. 提示词编译规则

选择本类型时，每个角色、场景、锚帧和故事板提示词均添加以下明确字段：

```text
【生产类型】真人中式神话故事片；不是历史复原。
【现实基座】……（演员身份、身体重量、可见光源、材质与接触）。
【中式神话图像学层】……（限定的光、云、莲座、木构、丝幡、玉白/鎏金反射等）。
【艺术加工】……；其标签：ICONOGRAPHY / CREATIVE。
【镜头要求】神话层服务人物选择，不遮蔽脸、眼神、手部和可达空间。
```

提示词不得只写“中式神话感”“东方奇幻感”或“史诗电影感”。必须描述谁在何处、哪一种材质如何受光、神话标记出现在哪里、怎样随角色动作发生反应，以及它推动的具体叙事变化。

## 6. 验收与修复

一张神话角色/场景图通过前检查：

1. 去掉光效后，仍能识别真人身份、动作、服装结构和空间方向；
2. 去掉人物后，仍能读出该场景已选择的中式神话地标、材质和光源关系；
3. 神话标记在同一角色的两张卡和下游锚帧中可复用，未随镜头随机变色、变形或消失；
4. 光轮、云、玉白反射、莲座、丝幡等不被误称为故事历史现场；
5. 不出现泛西式奇幻盔甲、游戏角色界面、塑料金像、无承重的悬浮建筑或与人物无关的特效堆积。

失败时优先修复一个变量：先修“神话标记缺失/过强”，再修“人物与神话光场不属同一光源”，最后修“空间地标不可达”。
