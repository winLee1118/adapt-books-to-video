# 影视场景生产设计：证据化布景、道具与可拍摄行动

在为故事电影或纪录电影建立场景资产、顶视图、九机位卡、镜头锚点或故事板前阅读本文件。它解决“人物站在空场景里”的失败：历史考证不是给画面贴一个时代标签，而是让空间、物件与人的行动彼此成立。

## 1. 场景不是背景图

一个可拍摄场景同时有四层，均须写进 `06-scene-bible.md` 的 `SCENE-xx-PRODUCTION-DESIGN-BREAKDOWN`：

1. **叙事任务**：人物此处要获得、隐藏、交付、拒绝或失去什么；阻力、出口和终态分别是什么。
2. **证据化空间**：建筑壳体、入口、光源和社会/礼仪功能，逐项回指 `ASSET-EVIDENCE-CARD`。历史层、图像学层和创作层不得混写。
3. **可用物件**：人物可拿、放、开启、绕过、避让、供养、整理或留下痕迹的道具。每件可见英雄道具和可辨认陈设都有证据、形制串、位置、初态、终态和使用者。
4. **生活痕迹与环境压力**：仅在证据许可范围内，通过磨损、积尘、日照、烟气、声源、动线和遮挡体现时间；它们必须服务行动或空间功能，不能以无依据的“古风杂物”填满画面。

一个场景若没有可见行动目标、阻力、可用空间/物件或稳定终态，则只是情绪插图，不可进入故事电影分镜。纪录电影的相应任务可为“证据问题 → 可见材料/地点 → 论证边界”，不得用戏剧道具伪装成史实。

## 1.1 考证到戏剧化的桥接

考证决定“可以确信什么、可以采用哪种物质形式、什么必须保留空缺”；戏剧化决定“人物现在想要什么、为何不能立刻得到、做了什么选择、画面如何发生可见变化”。两者必须并列记录，不能互相代替。

```text
DRAMATICIZATION-BRIDGE
TEXT：原文事实与定位。
HISTORY / ICONOGRAPHY：允许的空间、物件或行为范围及其限制。
INFERENCE：为使原文行动因果可见而作的最小连接；说明为什么合理、置信度及不得外推项。
CREATIVE：本场即时目标、阻力、选择、动作、台词、表情、节奏、调度、光线和镜头；明确不是原文逐秒记载或史实。
可见转折：观众在本场结尾能确认的状态改变。
```

若原文只说“归其舍”或“卖家宅”，可以创作一个有明确代价的离开／交付／回望动作；但必须把它标为 `CREATIVE`，并让动作发生在物理上可成立的房间、院落或门槛两侧。不得用一块单薄墙面、无去处的门洞或无缘由的空地替代人物可居住的世界。

## 2. 生产设计拆解表（生成前）

先完成并通过场景 `ASSET-EVIDENCE-CARD`，再填写：

```text
SCENE-01-PRODUCTION-DESIGN-BREAKDOWN
场景叙事功能：……；人物即时目标：……；阻力/阈值：……；终态：……。
DRAMATICIZATION-BRIDGE：TEXT / HISTORY 或 ICONOGRAPHY / INFERENCE / CREATIVE / 可见转折：……。
生产解释层：……；AEC：……；门禁：PASS。
空间功能：……；进/出动线：……；每个门洞的两侧体量、墙厚、抵达状态与离画合同：……；实景光及其故事作用：……。
HERO-PROP：PROP-01 | 人物要对它做什么 | TEXT/HISTORY/ICONOGRAPHY/INFERENCE/CREATIVE |
  证据 ID、形制串、否定串 | 初态 → 变化 → 终态 | 固定位置/持有人 | 必须可见的镜头节拍。
PROP-DRAMA-BRIDGE：该物在 TEXT/HISTORY/ICONOGRAPHY 中的允许范围；若为 CREATIVE，为什么需要它且不声称其为史实 | 谁想用它、为何受阻、如何触碰／开启／交付／拒绝 | 准备 → 接触/受力 → 可见变化 → 材料/声音余波 → 终态。
ACTION-SUPPORT：PROP-02… | 与 HERO-PROP 或人物目标的因果关系 | 同上。
布景簇：前景接触簇 / 中景行动簇 / 背景信息簇；每簇列物件 ID、证据边界、位置、
  使用/遮挡理由、允许出现的 Vnn；禁止只为“丰富”新增杂物。
显式留空：……；为何空、其文本/史料或叙事理由：……。
环境压力：……；可见/可听来源：……；对人物或道具状态的影响：……。
```

`HERO-PROP` 不等于昂贵或华丽。它是观众能据以理解人物目标、关系或代价的物；它必须在镜中经历准备、接触、状态变化与余波，不能只被摆在前景。若没有合适物件，必须明确“无英雄道具”及其叙事理由，并用可证实的门槛、距离、光、群体、声源或空间关系承担压力。原文未明说的创作性道具可以服务剧情，但必须标为 `CREATIVE`，不带可辨历史形制、不伪称某时期的真实用品，且同样锁定用途与初末状态。

## 3. 历史考证如何转为美术，而不是脑补

- 先区分文本明说的物件、选定时空可复原的物件、后世图像学物件和为拍摄作出的创作补足。后一类不能写成史实。
- 对会在中近景出现、会被拿取，或能识别社会/礼仪身份的物件，按 `visual-evidence.md` 建 `PROP-xx` 证据卡；至少两条独立可归属图像/实物证据、可数特征、形制串和否定串。
- 对小而不被辨认的布景物，仍记录来源行/证据簇和时代、材料、用途边界；不能因为它们小就混入现代、异地或不相容的物件。
- 文本没有交代室内陈设或建筑平面时，缩减可见空间或选择并标明的 `INFERENCE/CREATIVE`，不要用“古代/某地域感”自动补一整屋物件。
- 人物服饰、道具与空间必须落在同一生产解释层；图像学层可以控制宗教象征，不得覆盖历史层的建筑、日用品或人物物质文化。
- 不以“卖宅”“思念母亲”“准备供养”等剧情概念自动生成房契、钱袋、箱笼、香炉、供桌或祭器。经文明确出现的香花与供具应在其实际使用场景再研究形制；若当前镜头只是决定瞬间，优先让门槛／距离／光线承载压力，或使用明确的非历史 `CREATIVE` 行动载体。

## 4. 进入顶视图与九机位卡

顶视 `SCENE-xx-GEOMETRY-PLAN` 不写文字，但必须从生产设计拆解表读回：所有 HERO-PROP、行动支撑物、明确留空、进出线、演员区和实景光的位置。若某物不能在顶视图及空间锁中被定位，就不能在九机位卡里随机出现。

九机位卡不是九张空房间照。它应在不破坏同一空间的前提下，让 V03–V06 至少可看出：人物能到达什么、会被什么阻挡、关键物在哪个可拍摄关系中。物件可在某个机位被遮挡，但不得在反打中消失、漂移、复制或变成另一时代/形制。

## 5. 从生产设计到 ≤15 秒故事板

`SHOT-xx-CONTACT` 是单一连续生成段的**时间连续性检查表**，不是一页静态“站姿集合”，也不能替代文字分镜。进入出图前，每个片段须有一个 `ACTION-PROP-BEAT`：

```text
0.0 秒可见问题/目标与 HERO-PROP 初态
准备：视线、手、脚或重心如何朝物件/门槛移动
压力：阻力、距离、他人、环境或物件状态如何阻断
裂变：一次可见的触碰、放下、拿起、开启、交付、拒绝、失手或信息变化
余波：身体、材料、声音或环境的跟随反应
终态：人物、道具、空间关系和可接下一段的方向
```

一个连续片段保持同一布景与一条可连续执行的摄影机语言；允许在同一机位内以有动机的推进、跟移、焦点转移或人物全身调度改变画面，而不是六格机械复读同一远景。若需要硬切、不同镜头轴、无法连续完成的大幅穿越或另一个空间，拆成下一段 ≤15 秒视频，并用跨视频桥接完成剪辑。

六格中至少三格要能看出可检查的状态改变（人物—物件距离、手/脚接触、物件开合/位置、重心、遮挡、光或声源响应）；仅让人物左右看、换站姿或在空院中缓慢挪动，不构成影视化节拍。

## 6. 出图验收

逐项检查：

- 观众能否在首格识别“谁要什么、关键物/空间关系在哪里”；
- 道具是否有可追溯的形制、用途、持有人、初态、接触／受力、可见变化与终态，而非无因装饰；创作性道具是否明确标为 `CREATIVE` 且没有伪装成历史用品；
- 前/中/后景是否由行动、遮挡、光或声源建立，而非无依据堆物；
- 人物是否可以触及、绕行、开启、交付或被阻止，而非只站在场景内；
- 六格是否展示准备—压力—裂变—余波—终态，而非六个近似站姿；
- 纪录片重建是否清楚标示重建层，并没有把创作性补足说成考据事实。

失败时使用：`F49` 空舞台/无行动支点、`F50` 道具或布景无证据/无用途、`F51` 故事板没有可检查状态改变、`F53` 道具只有装饰或概念意义而没有可拍摄的状态变化。先回到生产设计拆解表修根因，再重出顶视图、锚点或单格；不要仅增加“电影感”“丰富细节”等词。
