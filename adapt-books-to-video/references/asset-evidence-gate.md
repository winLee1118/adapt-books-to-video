# 资产证据门禁：先检索、再验证、后生成

在写任何角色卡、场景顶视图、场景九机位卡、道具卡、镜头锚点或视频提示词之前阅读本文件。它将“有参考”变成可审核的生成前门禁：没有通过证据门禁的资产不得生成。

## 1. 不可跳过的顺序

每个资产按以下顺序完成，不能把提示词先写好再倒找依据：

```text
TEXT/EVIDENCE 查询 → ASSET-EVIDENCE-CARD → 证据冲突与空缺判定 → EVIDENCE-GATE → 资产提示词 → 生成后逐项比对
```

证据状态 `evidence_status`：PASS（可见主张成立）、HOLD（关键证据待补）、CONFLICT（证据冲突待解）。生成状态另用 PLANNED/PROMPT_ONLY/GENERATED，视觉 QA 另用 PENDING/PASS/FAIL，当前使用另用 ACTIVE/SUPERSEDED/BLOCKED。历史记录中的 PASS/PROMPT_ONLY 是两个维度；无生成能力不改变证据 PASS。详见 production-execution.md。

`INFERENCE` 和 `CREATIVE` 不是绕过门禁的理由：必须写清证据边界、可见后果、置信度和禁止模型擅自补全的内容。无法解释为有根据的推断时保持 `HOLD`。

## 2. 每个资产必须建立证据卡

在 `02-research-dossier.md` 为每个资产建一个 `ASSET-EVIDENCE-CARD`，并在 `asset-manifest.csv` 记录其 ID 和门禁状态。

```text
资产 ID / 类型 / 预期画面功能
文本定位：确切版本、卷/品/段；没有文本则写 NOT APPLICABLE
生产解释层：叙事世界 / 已选择的历史时空 / 已选择的图像学传统
可见主张表：主张 | 标签(TEXT/HISTORY/ICONOGRAPHY/INFERENCE/CREATIVE) |
  证据 ID/馆藏号或 DOI | 来源等级 | 支持范围 | 不支持/不得推导的内容 | 置信度
角色：年龄/社会身份/发式/衣层/材质/首饰/姿态各自的依据或空缺
场景：地点性质/平面/建筑体量与相邻空间/每个门窗的两侧与墙厚/家具/光源/群体/材料各自的依据或空缺；每个可跨越开口的离画合同或禁止跨越条件
生产设计：场景任务、人物目标/阻力、HERO-PROP/行动支撑物、布景簇、动线、实景光、初态/终态各自的依据、用途或空缺
道具：叙事类型（TEXT / HISTORY / ICONOGRAPHY / INFERENCE / CREATIVE）、检索名、至少两条独立图像证据（适用时）、可数特征、形制串和否定串；持有人、初态、准备、接触／受力、可见变化、材料／声音余波、终态；若为 CREATIVE，说明其非历史边界与不得伪装的形制
冲突与不确定性：候选解释、被拒绝解释、为什么不能合并
资产证据门禁：PASS / HOLD / CONFLICT；生成状态另记；审核人/日期；生成前检查结论
生成后核验：每个可见主张的通过/失败、对照图/页码、失败码和只改一个变量的修复
```

没有真实存在的文件、馆藏号、页码或稳定 URL 时，不能写成“已验证”。检索截图、AI 图、影视剧照、商家图片、未署名社媒图只能是发现线索，不可作为最终依据。

## 3. 查询协议

### 角色

先分开检索叙事身份与可见文化层：

1. 选定版本是否真的称其为该人物、该身份、该亲属关系；
2. 叙事世界是否给出可见身体、性别呈现、服装、行为或物件；
3. 如需历史重建，生产解释选择了哪一年代、地区与社会层级；
4. 为每一可见服装层、发式、饰物和行为找对应的学术/馆藏/同期图像证据；
5. 如使用后世宗教艺术，明确它只控制 `ICONOGRAPHY` 的哪些部分，不能倒推成故事发生时的历史事实。

“祭司”“贵族”“女子”“信众”等身份词不自动给出肤色、面部、服装、发式、阶层住宅或地域。必须先完成 `identity-and-setting-evidence.md` 的 `IDENTITY-TO-ASSET-RESEARCH`，再决定是否可进入角色生成。任何未在文本或选择的历史层中被支持的细节必须删除、降为不可辨认，或标 `INFERENCE` 并经门禁批准。

**表型禁止推导：**不得从种姓、族群、宗教、地域、阶层或叙事中的颜色词推断单一肤色、鼻眼脸型、发质、体型、智力、性格或道德特征。若生成需要一个具体演员外貌，把它记为 `CASTING_CHOICE`，并说明它只承担身份连续性；它不是该群体的“特征”。若用户要求历史写实，`CASTING_CHOICE` 仍不能替代已选时空与服饰／场景的实物或图像证据。

### 场景

先检索文本指定的场所和行为，再检索该解释层的建筑/考古/图像资料。再依 `cinematic-scene-production-design.md` 区分英雄道具、行动支撑物、功能性布景与明确留空；顶视 `SCENE-xx-GEOMETRY-PLAN` 的每个固定物、入口、光源、演员区和可用道具都必须回指 `ASSET-EVIDENCE-CARD` 中一行。每个门、窗、楼梯、廊道和可跨越边界还须回指两侧体量、墙厚、抵达状态与离画合同；缺失即为 F52。缺少平面或陈设依据时不能用“寺院感”“古印度风”填满空间，也不能让人物站在无叙事功能的空院中。

### 道具与艺术品

严格执行 `visual-evidence.md`。关键道具至少两条独立、可归属的图像/实物证据；艺术品在叙事中被看见时，先区分文本是否只说“像”，再选择特定时期/地区的 `ICONOGRAPHY` 方案。对每件前景道具再完成 `PROP-DRAMA-BRIDGE`：持有人、目标、阻力、准备、接触／受力、可见变化、材料／声音余波与终态。无文本或历史形制依据但确有戏剧需要时，可使用无地域、无时代断言的 `CREATIVE` 行动载体；它必须在提示词中声明“非历史形制”，不得伪装为房契、货币、祭器、香炉或其他特定时期物件。不得把后世名作、当代佛像或电商法器当成故事中的原物。

## 4. 审计提示词内的强制块

每个资产和视频审计版在 `【参考生成资产】` 前写。模型提交版只保留允许的可见结论与禁止推导内容，来源/日期留在审计和上传清单；通过 constraint_map 验证覆盖：

```text
【资产证据门禁】
资产：CHAR-01-PROFILE-CARD；门禁：PASS；证据卡：AEC-CHAR-01；核验日期：YYYY-MM-DD。
生产解释层：……。
TEXT：……（S-001，定位……）；HISTORY：……（S-002、S-003）；ICONOGRAPHY：……（S-004）。
INFERENCE/CREATIVE：……；不得推导：……。
生成允许的可见主张：……。
生成禁止补全：……。
```

若门禁不是 `PASS`，提示词不得进入模型队列。角色卡、顶视图、九机位卡、道具卡、镜头锚点、联系表和视频提示词都要复制对应的门禁 ID 与状态；镜头不得引用 `HOLD` 或 `REJECTED` 资产。

## 5. 生成后不是结束

批准前做“主张逐项比对”，而不是只判断好不好看：

- 图中每个显著服装层、饰物、建筑构件、家具、器物和光源是否在证据卡中；
- 是否把 `ICONOGRAPHY` 误称 `HISTORY`，或把 `INFERENCE` 画成确定事实；
- 是否出现无证据的地域符号、种族化面容、现代材料、混合时期或模型默认宗教物；
- 顶视图、九机位卡、镜头锚点与证据卡是否相互一致；
- 任一失败是否已按 F43–F47 登记并只修一个根因。

## 6. 失败码

| 编码 | 症状 | 首查与修复 |
|---|---|---|
| F43 | 资产在版本、文本定位或来源层未锁定时就进入生成 | 补选定版本、定位与 `ASSET-EVIDENCE-CARD`，资产退回 `HOLD` |
| F44 | 人物/场景细节被声称为史实，但仅有后世图像学或无依据参考 | 拆分 `HISTORY`、`ICONOGRAPHY`、`INFERENCE`，删除越界细节 |
| F45 | 场景/道具的时代、地域、材料或平面缺证据 | 补研究/馆藏来源；不能补则减少可见细节或 `DEFERRED` |
| F46 | 证据卡、来源链、门禁状态或生成后比对缺失/不一致 | 先修台账，冻结资产，不重抽 |
| F47 | 模型添加了未授权的文化、宗教、身份或历史细节 | 写入专用否定串，修上游锚点或删减画面；不得用美术词掩盖 |
| F48 | 从社会／种姓／族群标签推出肤色、表型、服装或住宅，或缺少 `IDENTITY-TO-ASSET-RESEARCH` | 资产退回 `HOLD`；拆分文本事实、历史物质文化与 `CASTING_CHOICE`，选择时空并补可归属来源 |
| F49 | 空间仅有壳体，人物没有经证据允许的行动支点或合理留空 | 回到生产设计拆解，锁定目标、阻力、动线与物件/空间关系 |
| F50 | 道具、陈设或生活痕迹没有证据边界、固定位置或人物用途 | 补证据卡/形制串和初末状态；不能补则删减，不用杂物填充 |
| F51 | 故事板六格没有准备—压力—变化—余波的可检查状态改变 | 写 `ACTION-PROP-BEAT`，先修锚点/调度，再重出失败格 |
| F53 | 道具只作装饰或概念暗示，没有持有人、用途、接触／受力和可见状态变化；或创作道具伪装成历史用品 | 补 `PROP-DRAMA-BRIDGE` 与初末状态；不能证明历史形制则降为无地域 `CREATIVE` 或移除 |

## 7. 研究深度

优先核验会被明确辨认或声称为历史事实的身份、服饰、关键道具、建筑/宗教形制；仍保留关键形制的双来源要求。远景不可辨细节采用有来源的类别级边界，不为不存在的可见主张捏造精度。演员走位、节奏、机位和虚构动机可作为声明过的 CREATIVE 决定；具体历史用品不能靠标签免除研究。先锁剧本所需场次，再深入可见资产。证据充分而无生成工具时仍可完成 PROMPT_ONLY 方案。
