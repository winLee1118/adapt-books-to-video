# 电影摄影与跨视频承接

## 1. 工作目标

把多个不超过 `15.0` 秒的生成片段编排成一条可剪辑的故事片或纪录片短片。每个片段只完成一个可见的叙事变化；摄影机、演员调度、光线、声音和剪辑边缘共同服务这个变化。不要把“电影感”“大师风格”或创作者姓名当作控制词。

所有输出、参考帧、分镜和成片均为 `16:9`。

先建立 `SEQ-xx`（段落）再写 `SHOT-xx`（片段）：

```text
SEQ-ID | 段落问题/情绪压力 | 摄影语言 | 空间轴线与行动方向 | 声音母题 | SHOT 链
SEQ-03 | 她是否会打开那封信 | 压力收束 | 门→桌为左至右；她面向右 | 纸张摩擦/远处列车 | SHOT-07 → SHOT-08 → SHOT-09
```

每个 `SHOT` 必须有可检查的 `入镜状态 → 可见变化 → 出镜状态`。若一个片段需要两次独立的信息转折、两种无关运镜、复杂多人交接或不可靠的长路径，拆成两个片段，并在剪辑中完成省略。

## 2. 去专名的摄影语言卡

每个 `SEQ` 只选择一种主摄影语言；可以借一个明确的辅助维度（例如声音桥），不能把互相冲突的镜头习惯堆在同一片段。实际生成提示词写下表的可见参数，不写导演/影片名称。

| 摄影语言 | 何时使用 | 可执行镜头规则 | 禁止误用 |
|---|---|---|---|
| `CLASSICAL_CONTINUITY` | 对话、行动和因果需清楚 | 先锁主轴、视线高度、屏幕方向；主镜交代关系，切到反应或细节只为新增信息/权力变化 | 用无故跨轴、无理由推镜伪造紧张 |
| `BLOCKING_REVEAL` | 信息通过人物走位、门框、遮挡显现 | 优先固定机位或短移位；人物越过前景/门口/光区时才揭示；停在新信息可读的位置 | 摄影机追逐每一个动作，或为“炫技”绕人一圈 |
| `PRESSURE_CONTAINMENT` | 犹豫、恐惧、权力压迫 | 用前景遮挡、负空间、受限景深；只在压力升级的可见触发后缓慢推进或改变焦点平面 | 把所有紧张都变成抖动、荷兰角或快速推拉 |
| `TABLEAU_AND_SCALE` | 地点、群像、历史规模或静默观察 | 静态/近静态横幅构图，让身体、风、光、环境在画内运动；前中后景各有可读层次 | 画面没有变化却强加无意义运镜 |
| `OBSERVATIONAL_DOCUMENTARY` | 有证据边界的现场、人物劳动和观察 | 眼平、可解释的站位、实景/可见光源、环境声；手持只在身体跟随或现场不稳定确有叙事原因时使用，并限制幅度 | 把随机晃动、低清或伪采访当成纪实性 |
| `SUBJECTIVE_BREAK` | 主观失衡、紧急感或认知断裂 | 先写主观触发；采用一条有限的跟随/弧移/倾斜路径，随后在可读的新构图稳定下来 | 全片持续摇晃，或用运动替代人物反应 |
| `LONG_TAKE_CHOREOGRAPHY` | 一次连续行动本身具有张力 | 在 ≤15 秒内只用一条连续路径、一个明确焦点策略和一个落点；先排演员路径、再排摄影机 | 同时要求环绕、升降、变焦、变焦点、多次反转和复杂群演 |
| `ELLIPTICAL_TRANSITION` | 过程不值得或无法稳定生成，但因果必须成立 | 用前一片段的原因与后一片段的结果相接；以动作、构图或声音保留观众方向感 | 强迫模型在一个片段里完成复杂全过程 |

摄影机移动的最低合同是：`为什么现在移动 → 什么可见事件触发 → 从哪里到哪里 → 速度/惯性 → 在何处停止 → 移动后新增哪一条信息`。没有答案就用固定机位。移动不等于高级；调度、构图、停顿和声音也能完成叙事。

## 3. 镜头链与转场合同

在 `19-cinematography-transition-plan.md` 为每条边写一行：

```text
FROM-SHOT | TO-SHOT | 共享向量 | 仅一种接入方式 | 第一帧新增信息 | 声音桥 | 后期责任 | 验收
SHOT-07 | SHOT-08 | 她右向视线、信封在右手、暖台灯左上、纸张摩擦 | MATCH_EYELINE | 反打中出现门缝的冷光 | L_CUT：纸声延续 0.4 秒 | 剪辑完成匹配切 | 视线/轴线/光向成立
```

`共享向量` 至少包含下列之一，并精确写入两端提示词：

- 动作：同一手势的起点/落点、相同物体的方向或运动；
- 构图：相同轮廓、色块、门框、地平线、屏幕位置或运动方向；
- 视线/空间：视线对象、180 度轴、人物左右关系、镜头高度；
- 光与环境：主光方向、烟雾/风/雨的方向和速度、时间状态；
- 声音：同一声源的进入、延续或离开，且标明 `J_CUT` / `L_CUT` 与后期责任。

每条边只能选择一个主要接入方式：

| 接入方式 | 必写条件 | 适合的用途 |
|---|---|---|
| `HARD_CUT_ON_ACTION` | 前镜切点动作，后镜在同一动作阶段或其可读后果进入 | 节奏、冲击、简洁省略 |
| `MATCH_ACTION` | 明确哪只手/哪件物体、方向、速度和接触状态匹配 | 拿起、放下、转身、开门 |
| `MATCH_COMPOSITION` | 两端对应的轮廓/色块/位置/方向，以及第二画面新增意义 | 时间、地点或意义的并置 |
| `MATCH_EYELINE` | 人物视线方向、被看对象位置、镜头轴线和高度 | 反应—揭示、对话反打 |
| `MATCH_SOUND` | 声源、响度/空间变化、画面从何时承接 | 画外空间、记忆、地点切换 |
| `J_CUT` | 下一镜声音先于下一镜画面出现；说明提前的秒数和声源 | 预告、压力、地点引入 |
| `L_CUT` | 前镜声音压到下一镜；说明延续的秒数和衰减 | 余韵、反应、连续动作 |
| `OCCLUSION_WIPE` | 前景遮挡物必须覆盖画面，后镜从同类遮挡退出；效果优先由剪辑完成 | 门框、人物掠过、黑暗、墙面 |
| `DISSOLVE_TIME_OR_MENTAL_SHIFT` | 明示时间/记忆/心理状态变化、两端可叠化元素和后期时长 | 明确的跳时或主观转换 |
| `BLACK_FIELD_PUNCTUATION` | 写明章节、不可逆后果或重大跳时理由，以及黑场前后的声画向量；文字仅后期叠加 | 段落断点，不能充当无理由换景 |
| `MOTIVATED_RUSH_TRANSITION` | 写明冲击、意识断裂、消失点或时空压缩触发，出镜/入镜方向或声音向量和稳定落点；后期完成 | 明确主观或大跨度转换，不能作为日常炫技 |

除非目标模型已核实支持原生多镜剪辑，所有切点、叠化、擦拭、J/L cut 都标为`后期制作`。视频模型只生成各自 ≤15 秒的单一连续镜头；不要要求它凭空完成未验证的转场特效。

## 4. 每段提示词的承接字段

每个视频提示词在 `【真实感物理合同】`之后、`【终帧状态】`之前写 `【跨视频承接与转场】`：

```text
【跨视频承接与转场】
入镜：来自 SHOT-07 的批准终帧 SHOT-07-END.png；逐字重述：她位于画面左三分之一、面向右，右手在胸前握住信封上缘，台灯自左上照亮手背，门缝在右后，纸张摩擦声已起。摄影机为眼平 50mm、稳定静止；动作轴从门到桌为左至右。
接入方式：MATCH_EYELINE。保留她的右向视线、左上暖光和左至右轴；本镜 0.0 秒新增门缝的冷光，不能提前出现来者。
声音桥：L_CUT，上一镜纸张摩擦延续 0.4 秒后由本镜门轴轻响接替；全部后期制作。
出口/交棒：在 14.6–15.0 秒，她把信封压到桌面，右手停住，目光抬向门；交给 SHOT-09 的首帧必须保留桌面信封、右向视线、左上暖光/右后冷光、门→桌左至右轴。剪切点为手指离开信封的第一帧；后期制作 MATCH_ACTION。
```

`SHOT-01` 没有上一镜时，`入镜` 与 `接入方式` 写“段落首镜，无前镜；以 SEQ-xx 摄影语言和首帧锚点进入”，不虚构一个入场转场；仍须为它的出口写交给下一镜的唯一桥接。最后一镜写“片段末镜，无下一镜；保留可剪辑的 0.5–1.0 秒稳定尾部”，并注明最终声音退出方式。

## 5. 摄影与剪辑验收

逐条检查，任一失败先修计划而不是叠加形容词：

- 每个片段 ≤15.0 秒，只有一个主要可见变化和一条可执行摄影机路径；
- 每段有一个摄影语言，并与剧本场次目标、权力/信息转折相匹配；
- 每次移动由人物/物体/信息变化触发，并有停止条件；固定机位被视为合格选择；
- 相邻片段重述了共享向量；反打不跨轴，视线高度、屏幕方向和镜头能量没有无故跳变；
- 每条边恰选一种主要转场，并区分“模型生成”与“后期制作”；
- 声音桥有声源、时长和进入/退出责任，未核实原生音频一律为后期；
- 纪录片重建不把未证实的镜头语言、动作或声音包装为史实；观察性手持必须有现场理由；
- 实际生成后，用批准终帧替换计划终帧；若共享向量已丢失，回到最早失配的片段修复或改用可成立的剪辑。
