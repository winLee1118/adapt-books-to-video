# 真人表演与微表情系统

使用 `character-realism-distillation.md` 把“角色活性”写成基线、触发、非机械的眨眼/视线/呼吸证据和稳定终态。本页保留七区表演细节；两页不得以情绪名称或固定周期动作代替可见因果。

端到端先按 [actor-performance-workflow.md](actor-performance-workflow.md) 建表演节拍；本页是观察工具，不是每个人都要填满的肌肉控制清单。

## 1. 表演原则

- 不只写情绪名称；把情绪翻译成可见肌肉、视线、呼吸和重心变化。
- 只描述当前景别能看见的部位。大全景不要虚构瞳孔细节；特写不要忘记颈部和呼吸。
- 一次表演只保留一个主情绪、一个次情绪和一个转折。
- 微表情必须有触发物：一句话、一个物件、一个声音、人物靠近或内部决定。
- 真人实拍默认克制、非对称、带轻微迟疑；禁止所有面部区域同时夸张。

## 2. 七区观察表

| 区域 | 按景别选用的观察项 | 常见错误 |
|---|---|---|
| 眉额 | 眉头距离、内外眉高度、额纹是否出现 | 两眉完全镜像、持续高挑 |
| 上下眼睑 | 睁开幅度、下睑张力、眨眼是否被抑制 | 死眼、无原因瞪眼 |
| 视线 | 注视对象、方向、高度、是否短暂逃离 | 看向不存在的人、反打视线错误 |
| 鼻翼与面颊 | 鼻翼呼吸、面颊绷紧/松弛、单侧变化 | 把所有情绪都写成鼻翼扩张 |
| 嘴唇 | 开合、抿压、嘴角单侧变化、唇部湿润度 | 无对白却持续张嘴、假笑 |
| 下颌与喉部 | 咬肌、下颌前后、吞咽、喉结/颈筋 | 下颌僵死、吞咽与对白冲突 |
| 呼吸与肩颈 | 吸/呼气阶段、胸肩幅度、头颈姿态 | 肩膀机械起伏、呼吸节奏跳变 |

## 3. 强度与时间弧

使用四级强度，但不把级别名称直接交给模型：

- **L1 痕迹级**：旁人可能错过；适合克制怀疑、回忆、压抑；
- **L2 可读级**：近景清楚但仍自然；真人电影默认；
- **L3 强烈级**：明显冲突或惊变，仍保持真实肌肉逻辑；
- **L4 极限级**：崩溃、疼痛、喊叫；只短暂使用并说明恢复阶段。

把表情拆成四段：

```text
中性基线 → 触发后的最小反应 → 情绪峰值/掩饰 → 新状态稳定
```

在需要变化的节拍标明事件触发与计划时间窗；有意维持状态不强造峰值。禁止从中性脸无过渡瞬间跳到峰值，也禁止峰值维持整个镜头。

## 4. 身体和手部

面部与身体必须一致：

- 恐惧：重心略后移，手指保护性弯曲，吸气短促；
- 决心：呼气后肩线稳定，重心向前脚，视线停止逃离；
- 羞愧：视线下降不等于低头到底，下颌回收，手寻找遮挡或抓握；
- 克制愤怒：下颌与指节先收紧，嘴唇变薄，呼吸变慢而非立刻怒吼；
- 悲悯：眉内侧轻抬、下眼睑柔化、嘴唇微开后合拢，身体距离缩短。

手部提示必须说明左右手、接触点、手指功能和道具朝向。复杂手势先生成静态锚点；出现手物穿插时优先修锚点，不用更长形容词掩盖。

## 5. 表情提示词合同

以下是内部诊断菜单。只为承担戏剧信息的角色选当前景别可见的1—2个主要区域；其余按需检查，不全部上传模型。背景人物以任务、朝向、间距和不同步反应为主：

```text
触发物：……
主/次情绪：……，强度从可见事实描述，不只写名称。
眉额：……
眼睑与眨眼：……
视线：从……移向……，在……秒锁定。
面颊/鼻翼：……
嘴唇：……
下颌/喉部：……
呼吸/肩颈：……
双手/重心：……
时间弧：中性基线…… → 最小反应…… → 峰值或掩饰…… → 稳定终态……
身份锁定：脸型、年龄、发型、服装、妆发与光线不得改变。
```

多人镜头分别写表演，不使用“众人震惊”概括。群演只定义分层反应比例和延迟，避免所有人同步张嘴、同步转头。

## 6. 验收

- 每个表情是否有触发物和时间弧？
- 眉、眼睑、视线、嘴唇、下颌、呼吸是否与用户要求和景别相符？
- 面部、手部、重心和道具互动是否属于同一情绪阶段？
- 是否存在僵硬凝视、过度对称、全脸同时夸张或无原因哭笑？
- 反打镜头的视线高度和方向是否匹配固定空间？
- 终格是否稳定，便于下一镜头延续？
- 身份锁与 `PERFORMANCE_BASELINE` 是否分开？眨眼、视线、呼吸和手部是否由注意力/触发驱动，而不是同步循环？
