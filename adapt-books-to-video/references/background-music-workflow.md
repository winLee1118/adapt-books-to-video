# 剧本与导演台驱动的背景音乐工作流

只在用户明确要求“分析/推荐 BGM”“准备 BGM 提示词”或“生成/制作/提交 BGM”时读取本页。它服务于既有图书转视频项目，不能创建平行项目状态，也不能默认触发音乐生成。

## 1. 触发与边界

- `ANALYZE_ONLY`：用户要求配乐判断或风格推荐。交付 `BGM-BRIEF`，不写可提交的生成请求。
- `PROMPT_ONLY`：用户要求提示词、方案或“准备发送给 API”。交付 `BGM-BRIEF` 与 `BGM-GENERATION-PAYLOAD`，但不调用任何音乐工具。
- `GENERATE_APPROVED`：用户明确要求生成、制作或提交一版 BGM，并已指定或授权可用入口。此时才调用已核验的音乐生成入口。
- 不以“有声音结构”“有导演台”“视频尚未配乐”推定 `GENERATE_APPROVED`。预剪与输出包中的音乐栏可以一直是 `PLANNED` 或 `PROMPT_ONLY`。
- 本页处理原创配乐、非人声环境音乐。需要歌词歌曲、角色演唱、旁白、音效或授权曲库时，先让用户明确目标并改用相应工作流；不得把它们伪称为 BGM。

## 2. 只读取当前生效的创作事实

先按 `active-release.json` 确定当前文件，再从下列存在且登记的文件中提取事实：`14-screenplay.md`、`20-director-design.md`、`07-storyboards.md`、`21-shotlist-9col.csv`、`24-precut-review.md` 与现有 `13-sound-edit-plan.md`。旧版本、未批准方案或文件名推测不得决定配乐。

按序列输出一个 `BGM-BRIEF`：

```text
SEQ-ID / 生效来源与版本 / 总时长和可用剪辑区间
叙事功能：建立、悬念、压力、转折、释然或余韵
情绪曲线：按时码列出强度 1–5、转折点和需要留白的位置
剪辑与镜头能量：切点、长镜、运动、呼吸点、声桥
对白/旁白保护：出现区间、优先级、必须避免的频段或编配密度
声音世界：环境声、拟音、已有音乐、不可覆盖的母题
音乐参数：时长、BPM 范围、节拍感、调式/音高重心、配器、动态、空间感、开头/结尾和循环或剪点策略
禁止项：人声/歌词、突发高潮、过度打击乐、文化或时代错配、已声明的特定排除项
状态：ANALYZE_ONLY / PROMPT_ONLY / GENERATE_APPROVED / GENERATED / QA_PASS / QA_FAIL
```

不要从画面题材直接推断宗教、地域或历史音乐。乐器和演奏法必须来自文本、导演设计、已批准的声音世界，或被明确标为 `CREATIVE` 的提案。

## 3. 大师参考与风格编译

可以根据视频内容向用户推荐配乐大师、流派或作品作为**分析参考**，并说明推荐理由，例如极简重复动机适合克制悬念、室内乐纹理适合亲密人物戏、低声部与缓慢脉冲适合庄严尺度感。不能声称模型能准确复刻某位大师，也不能复制具体作品的旋律、和声进行、录音纹理或可识别段落。

每个推荐必须同时产出无专名的 `STYLE-TRAIT-CARD`：

```text
叙事用途 | 情绪温度 | 节奏密度 | 速度范围 | 配器与音色 | 和声/调式张力 |
动态弧线 | 空间与混响 | 与对白的让位规则 | 明确排除项
```

提交给音乐模型的提示词只使用 `STYLE-TRAIT-CARD` 的可观察特征；不写作曲家、乐队、歌手、电影名称，不写“模仿”“同款”或受版权曲目的旋律指令。用户可保留大师名作为人类审阅标签，但它不进入 API 载荷。

## 4. 提示词与生成载荷

对每个已同意的序列写一个中文 `BGM-GENERATION-PAYLOAD`。它必须清楚地将剧本和导演台的结论编译为原创器乐提示词：

```text
目标：为 SEQ-ID 的 [时长] 秒原创无歌词背景音乐。
叙事与情绪：……
节奏与结构：0:00–…；…–结束，标明转折、留白和结尾方式。
音色与配器：……
动态与混音：……；对白/旁白出现时降低中频密度，保留人声清晰度。
风格特征：……（仅无专名 STYLE-TRAIT-CARD）。
限制：纯器乐；无人声、无歌词、无可识别旋律引用；不覆盖环境声与关键拟音；避免……。
```

- 目标工具为原创器乐时，选择已验证支持 `text_to_instrumental` 的模型。Flova 当前支持 `Suno 5` 与 `Mureka 8`；模型可用性、地区、会员和 credits 必须以实际入口为准，不承诺成本或可用性。
- 调用 Flova 时，遵循当前 Flova Skill 的项目、授权与 `flova run` 规则；不要臆造直接 API、CLI 参数或后台轮询命令。向 Flova 发送上述自然语言载荷，并要求只生成 BGM、不继续视频、配音或导出。
- 其他 API 只有在其实际文档已核验且用户授权使用时才可调用。未具备调用条件时，交付完整载荷即可。

## 5. 生成后审听、登记与剪辑

实际生成后，不凭文件名或模型返回文字宣称适配。登记 `BGM-ID`、模型/入口、提示词路径与哈希、真实时长、来源、状态和文件路径；将真实音频置于 `delivery/audio/`，在 `13-sound-edit-plan.md` 记录它服务的 `SEQ-ID`。

审听或要求用户审听：

- 时长是否覆盖所需区间，且起止、循环或淡出可剪；
- 是否确为无意人声、无歌词、无明显可识别引用；
- 情绪、节拍和峰值是否在导演台指定的节拍发生；
- 是否遮蔽对白、旁白、环境信息或有意静默；
- 是否需要后期音量自动化、EQ 让位、淡入淡出或分段剪接。

只有通过审听的真实文件可标为 `QA_PASS` 并进入最终音频层；否则保留为 `QA_FAIL` 或 `GENERATED`，不得自动替换旧 BGM。视频导出前还须确认音乐、对白、旁白、环境声和静默的最终混音关系。
