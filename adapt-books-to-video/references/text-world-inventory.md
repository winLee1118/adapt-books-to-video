# 文本世界清单

在选场景、写 `06-scene-bible.md` 或生成任何场景卡之前阅读本文件。

## 1. 解决的问题

场景资产与原文脱节，通常不是画得不好，而是**根本没把原文写了什么列出来**。只读故事梗概就去设计空间，会得到一个与文本无关的通用布景。

规则：**场景卡里的每一个可见要素，都必须能回指文本清单中的一行，或被显式标为 `CREATIVE` 并说明理由。**

## 2. 逐行通读，边读边登记

对选定的章/品，逐句通读原文，不得用摘要替代。每遇到下列任一项就登记一行：

| 类别 | 登记内容 |
|---|---|
| 地点 | 文本命名的处所、其所属界域、与其他地点的关系 |
| 在场者 | 每一类到场的存在，以及文本给出的数量词 |
| 主事者 | 说话者、提问者、被称名的个体 |
| 现象 | 光、云、音声、震动、香、雨华等文本明写的非人要素 |
| 物件 | 法器、供具、座、幢幡、器皿、衣着 |
| 行为 | 集会、礼拜、发问、供养、放光、说法 |
| 时间与因果 | 何时发生、由何引起、导致什么 |
| 数量与规模 | 文本用来表达规模的词，及其可视化后果 |

每行记录：`原文定位 | 原文用语 | 类别 | 可视化后果 | 标签 | 是否入镜`。

## 3. 在场者清单必须穷举

这是最常被跳过、也最常导致场景错误的一步。文本若列出多类到场者，必须**逐类登记**，不得合并成「众人」。


对每一类在场者继续记录：

- 文本是否描述其形貌？若无，进入图像学层，标 `ICONOGRAPHY`，不得当作 `TEXT`。
- 它在画面中的呈现方式：清晰个体、中景群体、远景轮廓、光影暗示，还是不入镜。
- 若不入镜，写明理由（如生成不可控、内容边界、时长限制），标为**显式省略**，不是遗漏。

## 4. 规模的可视化

文本用「无量」「不可说不可说」「百千万亿」表达规模时，不要直接翻译成数字，也不要缩成三五个人站在空台上。改写成可拍摄的画面语言，并登记选择：

- 用景深与遮挡表现延伸出画的群体；
- 用重复的形态节奏表现数量；
- 用云、光、雾划分层次，使远处群体不必逐个成形；
- 用近景个体 + 远景群体的对比建立尺度。

在清单中写明：本片用哪一种手法表现规模、代价是什么、哪些细节被牺牲。

## 5. 从清单到场景卡

场景空间锁和九机位卡必须由清单驱动，而不是凭氛围想象：

1. 从清单挑出**必须可见**的要素，列成 `SCENE-xx-SPATIAL-LOCK` 固定地标表；每个地标注明它来自哪一行清单、相对位置、朝向和可遮挡条件。
2. 挑一个主地标，要求它在默认九机位卡的至少六格可辨认；为 V01–V09 写可见/可遮挡/不应出现矩阵。
3. 把在场者按「清晰个体 / 中景群体 / 远景轮廓 / 光影暗示」分层，写进九机位分工，使场景一眼看得出这是文本描述的那场集会，而不是一处空地。
4. 文本明写的非人现象（如光明云、微妙之音的视觉对应）要么进入画面并标 `ICONOGRAPHY` 或 `CREATIVE`，要么在清单中显式省略。
5. 任何清单之外新增的物件、建筑或人群，标 `CREATIVE` 并写明为什么需要它。

## 6. 覆盖率验收

场景卡出图前逐项回答：

- 本章清单是否逐句通读得出，而非来自摘要？
- 在场者是否逐类登记，没有被合并成「众人」？
- 每一类在场者是否都有「呈现方式」或「显式省略 + 理由」？
- 场景卡的每个可见要素是否能回指清单某一行，或已标 `CREATIVE`？
- 文本明写的处所性质与规模，是否能从 `SCENE-xx-SPATIAL-LOCK` 和九机位卡的关系中看出来？
- 是否存在清单里份量很重、却在场景中完全消失且未说明的要素？

最后一问答「是」时，场景设计不合格，回到第 3 步重排分层，不要直接出图。
